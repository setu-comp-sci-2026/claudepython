## Challenge 2 — Fibonacci Sequence

The Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8, 13, 21, ...

Each number is the sum of the two before it.

Write a program that:
1. Asks the user how many Fibonacci numbers to generate
2. Prints them on one line separated by commas
3. Also prints the ratio of consecutive terms (should approach the golden ratio ≈ 1.618)

## Challenge 3 — Number Guessing Game

Write a complete number guessing game:
- Computer picks a random number between 1 and 100 (`import random; secret = random.randint(1, 100)`)
- Player has a maximum of 7 guesses
- After each guess, give "too high" / "too low" feedback
- If the player wins, print how many guesses it took
- If the player runs out of guesses, reveal the number
- Ask if they want to play again
