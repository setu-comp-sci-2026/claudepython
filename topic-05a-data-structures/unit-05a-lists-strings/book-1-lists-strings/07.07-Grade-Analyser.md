# Grade analyser

Create a file called **07_grade_analyser.py**.

You are going to build a small grade analysis program.

Start with:

~~~python
grades = [55, 72, 81, 90, 66]
~~~

## Task 1 - Total

Use a loop to calculate the total.

~~~python
total = 0
for grade in grades:
    total = total + grade

print("Total:", total)
~~~

## Task 2 - Average

Calculate and print the average.

## Task 3 - Highest and lowest

Use `max()` and `min()` to print the highest and lowest grade.

## Task 4 - Count passes

Count how many grades are greater than or equal to 40.

## Task 5 - Add user input

Ask the user to enter grades until they enter `-1`.

Store each grade in a list.

Then display:

- all grades
- average grade
- highest grade
- lowest grade
- number of passes
