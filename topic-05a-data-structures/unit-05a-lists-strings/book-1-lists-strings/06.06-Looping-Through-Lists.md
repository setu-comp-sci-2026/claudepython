# Looping through lists

Create a file called **06_looping_lists.py**.

~~~python
names = ["Ava", "Ben", "Cara", "Dylan"]

for name in names:
    print(name)
~~~

Run your code.

## Using indexes

~~~python
for i in range(len(names)):
    print(i, names[i])
~~~

## Using enumerate

~~~python
for i, name in enumerate(names, start=1):
    print(i, name)
~~~
