# List methods

Create a file called **05_list_methods.py**.

~~~python
shopping = []

shopping.append("milk")
shopping.append("bread")
shopping.append("eggs")

print(shopping)
~~~

Run your code.

## Remove items

~~~python
shopping.remove("bread")
print(shopping)

last_item = shopping.pop()
print("Removed:", last_item)
print(shopping)
~~~
