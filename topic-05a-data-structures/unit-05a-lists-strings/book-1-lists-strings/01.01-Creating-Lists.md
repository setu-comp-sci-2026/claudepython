# Creating lists

A list stores several values in one variable.

Create a file called **01_create_lists.py**.

Enter the following code:

~~~python
modules = ["Programming", "Maths", "Computer Systems", "Web Development"]
print(modules)
~~~

Run your code.

## Try it

Create a second list called `grades` containing five numbers.

Print the list.

~~~python
grades = [55, 72, 81, 90, 66]
print(grades)
~~~
