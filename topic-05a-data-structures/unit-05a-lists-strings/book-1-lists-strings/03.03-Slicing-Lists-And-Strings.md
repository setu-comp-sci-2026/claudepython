# Slicing lists and strings

Create a file called **03_slicing.py**.

~~~python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[:3])
print(numbers[-2:])
print(numbers[1:4])
~~~

Run your code.

## String slicing

Add this code:

~~~python
course = "Python Programming"

print(course[:6])
print(course[7:])
print(course[::-1])
~~~
