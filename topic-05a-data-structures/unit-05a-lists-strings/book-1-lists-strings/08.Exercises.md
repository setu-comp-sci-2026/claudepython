# Exercises

Complete these exercises after the main lab.

## Exercise 1 - Favourite foods

Create a list of five favourite foods.

Print each food on a separate line.

## Exercise 2 - Name cleaner

Ask the user to enter five names.

For each name:

- remove extra spaces
- convert it to title case
- store it in a list

Print the final list.

## Exercise 3 - Vowels

Ask the user to enter a word.

Count how many vowels are in the word.

## Exercise 4 - Shopping list menu

Create a menu that allows the user to:

1. Add an item
2. View all items
3. Remove an item
4. Exit

Use a list to store the shopping items.
