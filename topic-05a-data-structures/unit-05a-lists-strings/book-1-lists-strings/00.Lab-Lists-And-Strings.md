# Getting to know lists and strings

lists · arrays · indexing · slicing · methods · loops · strings

By the end of this lab, you should be able to:

- Explain how Python lists are similar to arrays.
- Create and print lists.
- Access list items using positive and negative indexes.
- Update list values.
- Slice lists and strings.
- Use common list methods such as `append()`, `remove()`, and `pop()`.
- Loop through a list.
- Use string methods such as `strip()`, `upper()`, `lower()`, `split()`, and `join()`.

## Before you begin

You should already be comfortable with:

- variables
- `input()` and `print()`
- `if`, `elif`, `else`
- `for` loops and `while` loops
- writing and calling functions
- running Python programs in Visual Studio Code

## Suggested project setup

1. Open Visual Studio Code.
2. Create a new folder called **ListsAndStringsLab**.
3. Create a separate Python file for each activity.
4. Run each file before moving on.

Suggested files:

- `01_create_lists.py`
- `02_indexing.py`
- `03_slicing.py`
- `04_string_methods.py`
- `05_list_methods.py`
- `06_looping_lists.py`
- `07_grade_analyser.py`
