# Indexing and updating lists

Create a file called **02_indexing.py**.

~~~python
animals = ["dog", "cat", "rabbit", "hamster"]

print(animals[0])
print(animals[2])
print(animals[-1])
~~~

Run your code.

## Update an item

Change `cat` to `kitten`.

~~~python
animals[1] = "kitten"
print(animals)
~~~
