# Activity 1 — A List of Colours

## Student Task

Create a list of colours and use a loop to draw a square where each side is a different colour.

Start with this list:

```python
colours = ["red", "green", "blue", "orange"]
```

Your program should:

1. create a turtle
2. loop through the list of colours
3. change the turtle colour each time
4. draw one side of a square for each colour

---

<details>
<summary><strong>Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(2)

colours = ["red", "green", "blue", "orange"]

for colour in colours:
    pen.color(colour)
    pen.forward(100)
    pen.right(90)

turtle.done()
```

</details>

# Activity 2 — Rainbow Circles

## Student Task

```python
rainbow = ["red", "orange", "yellow", "green", "blue", "indigo", "violet"]
```

Use a loop to draw one circle for each colour.

Each circle should:

- have a different colour
- be drawn slightly to the right of the previous circle

**Hint:** use `pen.penup()`, `pen.goto(x, y)`, and `pen.pendown()`.

---

<details>
<summary><strong>Solution</strong></summary>


# Activity 3 — Strings Are Sequences

## Student Task

Ask the user to enter their name.

Loop through each letter in the name and draw a small circle for each letter.

The colour of the circle should depend on the letter:

- vowels: red
- consonants: blue

Use this string to check vowels:

```python
vowels = "aeiou"
```

---

<details>
<summary><strong>Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(0)

name = input("Enter your name: ")
vowels = "aeiou"

x = -150

for letter in name.lower():
    pen.penup()
    pen.goto(x, 0)
    pen.pendown()

    if letter in vowels:
        pen.color("red")
    else:
        pen.color("blue")

    pen.circle(20)
    x = x + 45

turtle.done()
```

</details>

# Activity 4 — Shape Factory

## Student Task

Create a list of shape names:

```python
shapes = ["square", "triangle", "circle", "square"]
```

Loop through the list and draw each shape.

Your program should use `if`, `elif`, and `else` to decide which shape to draw.

Suggested shape rules:

- square: 4 sides
- triangle: 3 sides
- circle: use `pen.circle(40)`

---

<details>
<summary><strong>Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(0)

shapes = ["square", "triangle", "circle", "square"]

x = -180

for shape in shapes:
    pen.penup()
    pen.goto(x, 0)
    pen.pendown()

    if shape == "square":
        for i in range(4):
            pen.forward(60)
            pen.right(90)
    elif shape == "triangle":
        for i in range(3):
            pen.forward(70)
            pen.right(120)
    elif shape == "circle":
        pen.circle(35)
    else:
        print("Unknown shape:", shape)

    x = x + 120

turtle.done()
```

</details>

# Activity 5 — Dictionary of Turtle Commands

## Student Task

Create a dictionary that maps command words to turtle headings:

```python
commands = {
    "up": 90,
    "right": 0,
    "down": 270,
    "left": 180
}
```

Ask the user to enter a direction.

If the direction is in the dictionary:

1. set the turtle heading
2. move the turtle forward

If the direction is not in the dictionary, print an error message.

---

<details>
<summary><strong>Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(2)

commands = {
    "up": 90,
    "right": 0,
    "down": 270,
    "left": 180
}

direction = input("Enter direction: up, down, left or right: ").lower()

if direction in commands:
    pen.setheading(commands[direction])
    pen.forward(100)
else:
    print("Unknown direction")

turtle.done()
```

# Activity 6 — Turtle Adventure Map

## Student Task

Create a dictionary of locations.

Each key should be a place name.  
Each value should be an `(x, y)` coordinate.

Example:

```python
locations = {
    "home": (0, 0),
    "castle": (150, 100),
    "forest": (-120, 80),
    "lake": (100, -120)
}
```

Ask the user where they want to go.

If the place exists, move the turtle to that location.

---

<details>

```python

pen.speed(2)

    "home": (0, 0),
    "castle": (150, 100),
```

# Activity 7 — Drawing Flags with Dictionaries

## Student Task

Create a dictionary to store the colours of a flag.

Example:

```python
irish_flag = {
    "left": "green",
    "middle": "white",
    "right": "orange"
}
```

Draw the flag using three rectangles.

**Hint:** create a function called `draw_rectangle(colour)`.

---

<details>
<summary><strong>Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(0)

irish_flag = {
    "left": "green",
    "middle": "white",
    "right": "orange"
}

def draw_rectangle(colour):
    pen.fillcolor(colour)
    pen.begin_fill()
    for i in range(2):
        pen.forward(60)
        pen.right(90)
        pen.forward(120)
        pen.right(90)
    pen.end_fill()

x = -90

for section in irish_flag:
    pen.penup()
    pen.goto(x, 60)
    pen.pendown()
    draw_rectangle(irish_flag[section])
    x = x + 60

turtle.done()
```

</details>

# Activity 8 — Space Place: List of Dictionaries

## Student Task

Create a list of dictionaries to represent planets.

Each planet should have:

- name
- x coordinate
- size
- colour

Example:

```python
planets = [
    {"name": "Mercury", "x": -200, "size": 15, "colour": "grey"},
    {"name": "Venus", "x": -140, "size": 25, "colour": "orange"},
    {"name": "Earth", "x": -70, "size": 30, "colour": "blue"},
    {"name": "Mars", "x": 10, "size": 22, "colour": "red"}
]
```

Loop through the planets and draw each one.

Use `pen.write()` to label each planet.

---

<details>
<summary><strong>Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()

planets = [
    {"name": "Mercury", "x": -200, "size": 15, "colour": "grey"},
    {"name": "Venus", "x": -140, "size": 25, "colour": "orange"},
    {"name": "Earth", "x": -70, "size": 30, "colour": "blue"},
    {"name": "Mars", "x": 10, "size": 22, "colour": "red"}
]

for planet in planets:
    pen.penup()
    pen.goto(planet["x"], 0)
    pen.pendown()
    pen.color(planet["colour"])
    pen.begin_fill()
    pen.circle(planet["size"])
    pen.end_fill()

    pen.penup()
    pen.goto(planet["x"] - 20, -35)
    pen.color("black")
    pen.write(planet["name"])

turtle.done()
```

</details>

# Activity 10 — Final Challenge: Turtle Data Art

## Student Task

Create your own Turtle artwork using at least three of the following:

- a list of colours
- a string loop
- a dictionary
- a list of dictionaries
- a function
- a loop
- `append()`
- `if / elif / else`

Your artwork could be:

- a solar system
- a city skyline
- a garden
- a pattern generator
- a treasure map
- a flag collection
- a turtle game board

---

<details>
<summary><strong>Example Solution</strong></summary>

```python
import turtle

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()

buildings = [
    {"x": -200, "height": 120, "colour": "grey"},
    {"x": -120, "height": 180, "colour": "lightblue"},
    {"x": -40, "height": 90, "colour": "darkgrey"},
    {"x": 40, "height": 150, "colour": "purple"},
    {"x": 120, "height": 110, "colour": "brown"}
]

def draw_building(x, height, colour):
    pen.penup()
    pen.goto(x, -150)
    pen.pendown()
    pen.fillcolor(colour)
    pen.begin_fill()
    for i in range(2):
        pen.forward(60)
        pen.left(90)
        pen.forward(height)
        pen.left(90)
    pen.end_fill()

for building in buildings:
    draw_building(building["x"], building["height"], building["colour"])

turtle.done()
```

</details>
