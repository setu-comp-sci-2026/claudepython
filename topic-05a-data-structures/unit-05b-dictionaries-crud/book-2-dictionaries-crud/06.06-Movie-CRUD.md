# Movie CRUD program

Create a file called **06_movie_crud.py**.

You will build a menu-driven program that stores movies in a list of dictionaries.

## Starter code

~~~python
movies = []


def show_menu():
    print("
Movie Manager")
    print("1. Add movie")
    print("2. View movies")
    print("3. Search movie")
    print("4. Update rating")
    print("5. Delete movie")
    print("6. Exit")
~~~

## Add movie

~~~python
def add_movie():
    movie = {
        "title": input("Title: "),
        "year": int(input("Year: ")),
        "rating": int(input("Rating: "))
    }
    movies.append(movie)
    print("Movie added")
~~~

## View movies

~~~python
def view_movies():
    if len(movies) == 0:
        print("No movies stored")
    else:
        for movie in movies:
            print(f"{movie['title']} ({movie['year']}) - {movie['rating']}/5")
~~~

## Search movie

~~~python
def search_movie():
    title = input("Title to search for: ")
    for movie in movies:
        if movie["title"].lower() == title.lower():
            print(movie)
            return
    print("Movie not found")
~~~

## Main menu loop

~~~python
while True:
    show_menu()
    choice = input("Choose: ")

    if choice == "1":
        add_movie()
    elif choice == "2":
        view_movies()
    elif choice == "3":
        search_movie()
    elif choice == "6":
        break
    else:
        print("Invalid choice")
~~~
