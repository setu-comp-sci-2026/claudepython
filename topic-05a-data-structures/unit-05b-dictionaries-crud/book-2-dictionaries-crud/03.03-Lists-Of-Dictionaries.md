# Lists of dictionaries

Create a file called **03_list_of_dictionaries.py**.

A list of dictionaries can store multiple records.

~~~python
movies = [
    {"title": "Jaws", "year": 1975, "rating": 5},
    {"title": "Alien", "year": 1979, "rating": 5},
    {"title": "Shrek", "year": 2001, "rating": 4}
]
~~~

## Display all movies

~~~python
for movie in movies:
    print(movie["title"], movie["year"], movie["rating"])
~~~

## Format the output

~~~python
for movie in movies:
    print(f"{movie['title']} ({movie['year']}) - {movie['rating']}/5")
~~~
