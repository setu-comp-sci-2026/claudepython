# Exercises

## Exercise 1 - Student manager

Create a list of student dictionaries.

Each student should have:

- name
- student number
- course
- mark

Allow the user to:

1. Add student
2. View students
3. Search by student number
4. Exit

## Exercise 2 - Filtering

Using the same student list, display:

- all students who passed
- all students with a mark over 70
- the average mark

## Exercise 3 - Update

Add an option to update a student's mark.

## Exercise 4 - Delete

Add an option to delete a student by student number.
