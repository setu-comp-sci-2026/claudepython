# Getting to know dictionaries and simple CRUD

dictionaries · records · keys · values · lists of dictionaries · simple CRUD

By the end of this lab, you should be able to:

- Create a dictionary to represent one record.
- Access dictionary values using keys.
- Add and update dictionary values.
- Use `keys()`, `values()`, `items()`, and `get()`.
- Store many records using a list of dictionaries.
- Search through a list of dictionary records.
- Build a simple menu-driven CRUD program.

## Before you begin

You should already be comfortable with:

- variables
- `input()` and `print()`
- selection and loops
- functions
- lists and strings

## Suggested project setup

1. Open Visual Studio Code.
2. Create a new folder called **DictionariesCrudLab**.
3. Create a separate Python file for each activity.
4. Run each file before moving on.

Suggested files:

- `01_dictionary_basics.py`
- `02_dictionary_methods.py`
- `03_list_of_dictionaries.py`
- `04_search_records.py`
- `05_add_records.py`
- `06_movie_crud.py`
