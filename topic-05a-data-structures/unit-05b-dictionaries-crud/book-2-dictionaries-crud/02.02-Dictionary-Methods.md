# Dictionary methods

Create a file called **02_dictionary_methods.py**.

~~~python
student = {
    "name": "Ava",
    "age": 19,
    "course": "Computing"
}

print(student.keys())
print(student.values())
print(student.items())
~~~

Run your code.

## Loop through a dictionary

~~~python
for key, value in student.items():
    print(key, value)
~~~

## Safer access with get()

~~~python
print(student.get("name"))
print(student.get("email"))
print(student.get("email", "No email stored"))
~~~
