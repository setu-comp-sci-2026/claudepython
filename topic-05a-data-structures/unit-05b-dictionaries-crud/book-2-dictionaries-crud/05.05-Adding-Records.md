# Adding records

Create a file called **05_add_records.py**.

Start with an empty list.

~~~python
movies = []
~~~

## Add one movie

~~~python
movie = {
    "title": input("Title: "),
    "year": int(input("Year: ")),
    "rating": int(input("Rating: "))
}

movies.append(movie)
print(movies)
~~~

## Add many movies

Use a loop to keep adding movies until the user enters a blank title.

~~~python
while True:
    title = input("Title, or blank to stop: ")

    if title == "":
        break

    movie = {
        "title": title,
        "year": int(input("Year: ")),
        "rating": int(input("Rating: "))
    }

    movies.append(movie)

print(movies)
~~~
