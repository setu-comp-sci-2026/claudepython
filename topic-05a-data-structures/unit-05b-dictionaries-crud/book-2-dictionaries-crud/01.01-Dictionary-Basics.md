# Dictionary basics

A dictionary stores values using keys.

Create a file called **01_dictionary_basics.py**.

~~~python
movie = {
    "title": "Jaws",
    "year": 1975,
    "rating": 5
}

print(movie)
print(movie["title"])
print(movie["year"])
~~~

Run your code.

## Add a new key-value pair

~~~python
movie["genre"] = "Thriller"
print(movie)
~~~

## Update a value

~~~python
movie["rating"] = 4
print(movie)
~~~
