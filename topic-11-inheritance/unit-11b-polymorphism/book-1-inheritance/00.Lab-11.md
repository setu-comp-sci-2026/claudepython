# Lab 11 — Inheritance

## Objectives

By the end of this lab you will be able to:

- Create a subclass using `class Child(Parent):`
- Call `super().__init__()` to initialise inherited attributes
- Override `__str__` and other dunder methods in subclasses
- Use `isinstance()` to test object type at runtime
- Demonstrate polymorphism by storing mixed types in one list
