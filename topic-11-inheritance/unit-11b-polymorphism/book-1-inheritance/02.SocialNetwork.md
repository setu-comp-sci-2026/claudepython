# Step 2 — The Social Network Example

Build a mini social network with three classes.

## 2.1 — `Person` base class

Use the `Person` class from Step 1.

## 2.2 — `FreeUser` subclass

Create `free_user.py`:

```python
from person import Person

class FreeUser(Person):
    def __init__(self, name: str, email: str,
                 max_posts: int = 10):
        super().__init__(name, email)
        self.__max_posts = max_posts

    def get_max_posts(self) -> int:
        return self.__max_posts

    def __str__(self) -> str:
        return (f"FreeUser: {self.get_name()} "
                f"(max {self.__max_posts} posts/month)")
```

## 2.3 — `PremiumMember` subclass

Create `premium_member.py`:

```python
from person import Person

class PremiumMember(Person):
    def __init__(self, name: str, email: str,
                 subscription: str):
        super().__init__(name, email)
        if subscription not in ("Silver", "Gold", "Platinum"):
            raise ValueError(f"Invalid subscription: {subscription}")
        self.__subscription = subscription

    def get_subscription(self) -> str:
        return self.__subscription

    def __str__(self) -> str:
        return (f"PremiumMember: {self.get_name()} "
                f"[{self.__subscription}]")
```

## 2.4 — Driver

```python
from free_user import FreeUser
from premium_member import PremiumMember

users = [
    FreeUser("Alice", "alice@example.com", 10),
    PremiumMember("Bob", "bob@example.com", "Gold"),
    FreeUser("Carol", "carol@example.com"),
    PremiumMember("Dave", "dave@example.com", "Platinum"),
]

for user in users:
    print(user)
```
