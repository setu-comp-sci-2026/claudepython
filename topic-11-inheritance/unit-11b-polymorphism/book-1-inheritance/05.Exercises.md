# Exercises

## Exercise 1 — Animal Hierarchy

```python
class Animal:
    def __init__(self, name: str):
        self.__name = name
    def get_name(self) -> str:
        return self.__name
    def speak(self) -> str:
        return "..."

class Dog(Animal):
    def speak(self) -> str:
        return "Woof!"

class Cat(Animal):
    def speak(self) -> str:
        return "Meow!"

class Parrot(Animal):
    def __init__(self, name: str, phrase: str):
        super().__init__(name)
        self.__phrase = phrase
    def speak(self) -> str:
        return self.__phrase
```

Create these classes and test polymorphism with a list of animals.
