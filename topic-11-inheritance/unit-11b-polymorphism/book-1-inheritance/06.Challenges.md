# Challenges

## Challenge 1 — Full Social Network

Build a social network system:
- `Person` base class with name, email, join_date
- `FreeUser(Person)` with post limit and list of posts
- `PremiumMember(Person)` with subscription tier and unlimited posts
- `AdminUser(PremiumMember)` with access level and ability to ban users

Add a `Network` class (like Shop) that manages a list of `Person` objects with add, find, remove, and display methods. Add a `ban_user(email)` method that only works if the caller is an `AdminUser`.

## Challenge 2 — Zoo System

Create a zoo management system:
- `Animal` base class with name, species, age
- `Mammal(Animal)` with fur colour
- `Bird(Animal)` with wingspan
- `Reptile(Animal)` with is_venomous

Store all in a `Zoo` class list. Display sorted by species. Filter by type using `isinstance`.

## Challenge 3 — Payroll Calculator

Create an employee payroll system:
- `Employee` base class with name, employee_id
- `SalariedEmployee(Employee)` with annual_salary
- `HourlyEmployee(Employee)` with hourly_rate, hours_per_week
- `CommissionEmployee(Employee)` with base_salary, sales, commission_rate

Each must implement `weekly_pay() -> float`. Use polymorphism to calculate total payroll from a mixed list.
