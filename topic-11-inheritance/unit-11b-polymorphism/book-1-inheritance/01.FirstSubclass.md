# Step 1 — Creating Your First Subclass

## 1.1 — The Person parent class

Create `person.py`:

```python
class Person:
    def __init__(self, name: str, email: str):
        self.__name = name
        self.__email = email

    def get_name(self) -> str:
        return self.__name

    def get_email(self) -> str:
        return self.__email

    def __str__(self) -> str:
        return f"Person: {self.__name} <{self.__email}>"
```

## 1.2 — A simple subclass

Create `student.py`:

```python
from person import Person

class Student(Person):
    pass   # inherits everything for now

s = Student("Alice", "alice@example.com")
print(s.get_name())    # Alice
print(s.get_email())   # alice@example.com
print(s)               # Person: Alice <alice@example.com>
```

## 1.3 — Add a student-specific attribute

```python
class Student(Person):
    def __init__(self, name: str, email: str,
                 student_id: str):
        super().__init__(name, email)
        self.__student_id = student_id

    def get_student_id(self) -> str:
        return self.__student_id

    def __str__(self) -> str:
        return (f"Student [{self.__student_id}]: "
                f"{self.get_name()}")
```
