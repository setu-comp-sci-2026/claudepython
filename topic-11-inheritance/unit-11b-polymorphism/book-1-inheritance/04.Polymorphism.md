# Step 4 — Polymorphic Behaviour

## 4.1 — Mixed list of users

```python
from person import Person
from free_user import FreeUser
from premium_member import PremiumMember

users = [
    FreeUser("Alice", "alice@example.com", 10),
    PremiumMember("Bob", "bob@example.com", "Gold"),
    FreeUser("Carol", "carol@example.com", 5),
]

# Polymorphic loop — each prints via its own __str__
for user in users:
    print(user)
```

## 4.2 — Using `isinstance()`

```python
for user in users:
    print(f"\n{user.get_name()}:")
    if isinstance(user, PremiumMember):
        print(f"  Premium plan: {user.get_subscription()}")
    elif isinstance(user, FreeUser):
        print(f"  Post limit: {user.get_max_posts()}")
```

## 4.3 — Count by type

```python
premium_count = sum(1 for u in users
                    if isinstance(u, PremiumMember))
free_count = sum(1 for u in users
                 if isinstance(u, FreeUser))
print(f"Premium: {premium_count}, Free: {free_count}")
```

## 4.4 — `__eq__` for Person

Add to `Person`:
```python
def __eq__(self, other) -> bool:
    if not isinstance(other, Person):
        return NotImplemented
    return self.__email == other.__email
```
