# Step 3 — Using super()

## 3.1 — Extending `__str__`

Add to `PremiumMember`:

```python
def describe(self) -> str:
    base = super().__str__()   # "Person: Bob <bob@...>"
    return f"{base} | Plan: {self.__subscription}"
```

## 3.2 — Multi-level inheritance

Create `admin_user.py`:

```python
from premium_member import PremiumMember

class AdminUser(PremiumMember):
    def __init__(self, name: str, email: str,
                 subscription: str, access_level: int):
        super().__init__(name, email, subscription)
        self.__access_level = access_level

    def get_access_level(self) -> int:
        return self.__access_level

    def __str__(self) -> str:
        return f"{super().__str__()} [Admin L{self.__access_level}]"
```

Test:
```python
admin = AdminUser("Eve", "eve@example.com", "Platinum", 5)
print(admin)
# PremiumMember: Eve [Platinum] [Admin L5]
```
