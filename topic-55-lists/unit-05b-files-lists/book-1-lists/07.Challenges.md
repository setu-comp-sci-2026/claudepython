## Challenge 1 — Student Grade Manager

Build a complete student grade management system that:
1. Reads student data from a CSV file (name, score1, score2, score3)
2. Calculates average, letter grade, and pass/fail for each student
3. Displays a formatted table
4. Writes a summary report to a file
5. Lists top 3 students and any students who failed

The CSV file format:
```
name,score1,score2,score3
Alice,88,92,78
Bob,74,68,81
Carol,95,91,98
Dave,55,62,48
Eve,80,75,83
```

Grade bands: A (90+), B (80-89), C (70-79), D (60-69), F (below 60)

## Challenge 3 — Text File Word Search

Write a program that reads a text file and supports:
1. *Search* — find all lines containing a given word (case-insensitive), show line numbers
2. *Replace* — replace all occurrences of a word with another word and save to a new file
3. *Extract* — extract all sentences containing a given word into a new file
4. *Statistics* — count unique words, top 10 most frequent words

```python
def search_lines(filename, keyword):
    """Return list of (line_number, line_text) for matching lines."""
    results = []
    with open(filename, "r") as f:
        for i, line in enumerate(f, start=1):
            if keyword.lower() in line.lower():
                results.append((i, line.strip()))
    return results
```
