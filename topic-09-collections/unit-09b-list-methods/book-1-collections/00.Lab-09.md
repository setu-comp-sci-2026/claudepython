# Lab 09 — Collections

## Objectives

By the end of this lab you will be able to:

- Build a menu-driven CRUD system for the Shop app
- Use list comprehensions to filter and transform lists of objects
- Sort lists of objects using `sorted()`, `key=`, and `lambda`
- Apply the `match` statement for menu dispatch
- Use `get_int_input()` for safe user input

**Extend your `lab08/` code** or create a new `lab09/` folder with copies of `product.py`, `shop.py`, and a new `driver.py`.
