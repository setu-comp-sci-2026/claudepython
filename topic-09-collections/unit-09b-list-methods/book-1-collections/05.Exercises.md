# Exercises

## Exercise 1 — Price Range Filter

Add a method to `Shop`:
```python
def get_in_price_range(self, min_price: float, max_price: float) -> list:
    return [p for p in self.__products
            if min_price <= p.get_price() <= max_price]
```

In the driver, prompt for min and max price and display matching products.

## Exercise 3 — Total by Category

If you added `category` to `Product`, write a function that returns the total value of products in a given category:

```python
def total_by_category(shop: Shop, category: str) -> float:
    return sum(p.get_price()
               for p in shop.get_all_products()
               if p.get_category() == category)
```
