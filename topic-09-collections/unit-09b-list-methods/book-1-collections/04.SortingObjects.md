# Step 4 — Sorting Lists of Objects

## 4.1 — Sort products by price

```python
products = shop.get_all_products()

by_price = sorted(products, key=lambda p: p.get_price())
print("\nSorted by price (low to high):")
for p in by_price:
    print(f"  €{p.get_price():.2f}  {p.get_name()}")
```

## 4.2 — Sort by name

```python
by_name = sorted(products, key=lambda p: p.get_name().lower())
print("\nSorted alphabetically:")
for p in by_name:
    print(f"  {p.get_name()}")
```

## 4.3 — Reverse sort

```python
most_expensive_first = sorted(
    products,
    key=lambda p: p.get_price(),
    reverse=True
)
```

## 4.4 — Add sort methods to Shop

In `shop.py`:

```python
def get_sorted_by_price(self, reverse: bool = False) -> list:
    return sorted(self.__products,
                  key=lambda p: p.get_price(),
                  reverse=reverse)

def get_sorted_by_name(self) -> list:
    return sorted(self.__products,
                  key=lambda p: p.get_name().lower())
```

In `driver.py`, add to the menu:
```python
case "6":
    print("\nSorted by price:")
    for p in shop.get_sorted_by_price():
        print(f"  {p}")
```
