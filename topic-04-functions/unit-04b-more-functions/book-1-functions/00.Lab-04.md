# Lab 04 — Functions

## Objectives

By the end of this lab you will be able to:

- Define and call your own functions using `def`
- Use **positional**, **keyword**, and **default** parameters
- Use `return` to send values back to the caller
- Work with common **string methods** (upper, lower, strip, split, join, replace)
- Format output using **f-strings** with format specifiers
- Write a **recursive** function with a correct base case

## Setup

Create a new folder `lab04` and a file `functions.py` in VS Code.
