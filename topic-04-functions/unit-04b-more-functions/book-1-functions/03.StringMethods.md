# String Methods

## Step 1 — Case Methods

```python
message = "hello, world!"
print(message.upper())      # HELLO, WORLD!
print(message.lower())      # hello, world!
print(message.title())      # Hello, World!
print(message.capitalize()) # Hello, world!
```

## Step 2 — Strip and Find

```python
# Removing whitespace
raw = "   python   "
print(raw.strip())          # "python"
print(raw.lstrip())         # "python   "
print(raw.rstrip())         # "   python"

# Searching
text = "The cat sat on the mat"
print(text.find("cat"))     # 4
print(text.count("at"))     # 3
print(text.startswith("The"))  # True
print(text.endswith("mat"))    # True
```

## Step 3 — Split and Join

```python
# Splitting
sentence = "Python is a great language"
words = sentence.split()
print(words)         # ['Python', 'is', 'a', 'great', 'language']
print(len(words))    # 5

csv = "Alice,25,Dublin,Engineer"
fields = csv.split(",")
name, age, city, job = fields
print(f"{name} works as a {job} in {city}")

# Joining
rejoined = " | ".join(words)
print(rejoined)      # Python | is | a | great | language
```

## Step 4 — Replace and Format

```python
template = "Dear {name}, your balance is {amount}."
filled = template.replace("{name}", "Alice").replace("{amount}", "€150.00")
print(filled)

# f-strings with format specifiers
price = 1234.5678
print(f"Price: €{price:,.2f}")      # €1,234.57
print(f"Price: €{price:.0f}")       # €1235

ratio = 0.8523
print(f"Pass rate: {ratio:.1%}")    # 85.2%
```
