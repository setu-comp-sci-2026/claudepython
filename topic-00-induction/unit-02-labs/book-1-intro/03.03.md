# The Python REPL

In the lecture, you saw the Python REPL (Read-Evaluate-Print Loop) — an interactive way to run Python one line at a time without creating a file.  It is perfect for experimenting quickly.

## Opening the REPL

Open the integrated terminal in VS Code:

- Go to **View > Terminal**, or
- Press `` Ctrl+` `` (Windows/Linux) or `` Cmd+` `` (macOS)

In the terminal, type the following and press **Enter**:

~~~
python3
~~~

> On Windows you may need to type `python` instead of `python3`.

You should see a prompt like this:

~~~
>>>
~~~

This is the REPL.  Python is waiting for you to type something.

## Trying it Out

Type each of the following lines and press **Enter** after each one.  Observe the output Python gives you immediately:

~~~python
>>> print("hello")
hello
>>> 2 + 2
4
>>> 10 - 3
7
>>> 6 * 7
42
~~~

Notice that when you type an expression like `2 + 2`, the REPL evaluates it and prints the result straight away — you do not even need `print()`.

## Exiting the REPL

When you are finished, type the following to exit the REPL and return to the normal terminal prompt:

~~~python
>>> exit()
~~~
