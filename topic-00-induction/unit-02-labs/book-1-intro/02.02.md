# Hello, World!

The traditional first program in any language is one that prints the words *Hello, World!* to the screen.

## Creating a Python File

In VS Code, create a new file:

1. Go to **File > New File**
2. Save it immediately using **File > Save As**
3. Name it `lab01_step02.py` and save it in your `programming-labs-> topic01` folder

The `.py` extension tells VS Code (and your computer) that this is a Python file.  You should see the Python logo appear in the tab.

## Writing Your First Line of Code

Type the following into your file — avoid copy-pasting; typing it yourself helps you learn faster:

~~~python
print("Hello, World!")
~~~

The `print()` function displays whatever is inside the brackets in the terminal.  The text `"Hello, World!"` is surrounded by double quotes, which tells Python it is a piece of text.

## Running Your Code

Right-click anywhere inside the editor and select **Run Python File in Terminal**.

You should see the terminal open at the bottom of VS Code and display:

~~~
Hello, World!
~~~

Congratulations — you have just run your first Python program!

## Experimenting

Change the text inside the quotes to something else, for example your own name:

~~~python
print("Hello, my name is Siobhan!")
~~~

Run the file again and observe the new output.  Try a few different messages.

Be careful about saving your changed code.  The file must be saved before the changes take effect.
