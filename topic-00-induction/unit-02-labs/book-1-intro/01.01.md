# Your First Python Lab

Welcome to your first Python lab!  In the lectures you:

- learned what Python is and how it works (interpreted, bytecode, PVM)
- saw why Python became the standard for data science and AI
- installed Python and Visual Studio Code

In this lab, we will write and run real Python code for the first time.  By the end you will be able to:

- create and run a Python file in VS Code
- use the Python REPL interactively
- print output to the terminal
- perform arithmetic
- store values in variables

## Opening VS Code

Having decided on your filing system, use e.g. the Documents folder on your Mac or on your  Windows computer. Create a folder called e.g. SETU. Create a folder for each module you are working on this semester. Call the programming folder `programming-labs`.  Decide on whether to create a folder per topic or per week (e.g. topic-00-induction, topic-01-data-types). 

Open Visual Studio Code on your computer.  You should see the Welcome tab.
Open the programming-labs folder. You should now be in the `programming-labs` folder. You should use this for all programming labs and assignments.
