# Variables

Instead of writing numbers directly every time, you can store values in **variables** and refer to them by name.  This makes your code easier to read and easier to change.

## Defining a Variable

A variable is created by writing a name, then `=`, then a value:

~~~python
x = 10
~~~

From this point on, every time Python sees `x` it uses the value `10`.

## Your First Variable Program

In VS Code, create a new file and save it as `lab01_step05.py`.  Type the following code:

~~~python
x = 10
y = 5

print(x + y)
print(x - y)
print(x * y)
print(x / y)
~~~

Run the file.  You should see:

~~~
15
5
50
2.0
~~~

## Changing a Variable's Value

Now change the value of `x` from `10` to `20`:

~~~python
x = 20
y = 5
~~~

Run the file again.  All four results update automatically — you only had to change one line.

This is one of the main reasons we use variables: change the value once and every calculation that uses it updates instantly.

## Printing with Labels

It is often useful to print a label alongside a value so the output is easier to read.  Update your file to include labels:

~~~python
x = 10
y = 5

print("x + y =", x + y)
print("x - y =", x - y)
print("x * y =", x * y)
print("x / y =", x / y)
~~~

Run the file.  The output should now look like:

~~~
x + y = 15
x - y = 5
x * y = 50
x / y = 2.0
~~~

Save your work using the naming convention `labXX_stepYY.py`.
