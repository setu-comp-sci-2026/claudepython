# Arithmetic in Python

Python can be used as a powerful calculator.  In the lecture you saw it used directly in the REPL — now we will write arithmetic into a proper Python file.

## Arithmetic Operators

Python supports the following arithmetic operators:

| Operator | Meaning        | Example  | Result |
|----------|----------------|----------|--------|
| `+`      | Addition       | `5 + 3`  | `8`    |
| `-`      | Subtraction    | `10 - 4` | `6`    |
| `*`      | Multiplication | `3 * 7`  | `21`   |
| `/`      | Division       | `15 / 4` | `3.75` |

## Creating the File

In VS Code, create a new Python file and save it as `lab01_step04.py`.

Type in the following code — do not copy-paste:

~~~python
print(5 + 3)
print(10 - 4)
print(3 * 7)
print(15 / 4)
~~~

Run the file and check the output:

~~~
8
6
21
3.75
~~~

Notice that dividing two whole numbers (`15 / 4`) gives a decimal result (`3.75`).  Python handles this automatically.

## Combining Operators

You can combine operators in a single expression, just like in maths.  Add the following lines to your file:

~~~python
print(2 + 3 * 4)
print((2 + 3) * 4)
~~~

Run the file and observe the difference.  Python follows standard mathematical precedence — multiplication happens before addition unless you use brackets.
