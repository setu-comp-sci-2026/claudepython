# Exercises

The exercises below are based on the material covered in the previous steps.  For each exercise, create a new Python file in VS Code and save it using the naming convention `lab01_exerciseXX.py`.

## Exercise 1 (print)

In Step 2 we used `print()` to display a message.  

Create a new Python file and write code that prints **three separate lines** of text — each on its own line.  For example:

~~~
Python is an interpreted language.
It was created by Guido van Rossum.
It is widely used in data science and AI.
~~~

The exact text is up to you — write three facts about Python that you remember from the lectures.

Save your work.

## Exercise 2 (arithmetic)

In Step 4 we used arithmetic operators.  

Create a new Python file and write code that prints the result of **five different arithmetic expressions** — one per line.  Use at least three different operators (`+`, `-`, `*`, `/`).  For example:

~~~python
print(100 + 25)
print(200 - 75)
print(12 * 8)
print(100 / 4)
print(3 * 10 + 5)
~~~

Run the file and check each result is what you expect.

Save your work.

## Exercise 3 (variables and arithmetic)

In Step 5 we stored values in variables.

Create a new Python file and define two variables, `a` and `b`, with values of your choosing.  Then print the result of all four arithmetic operations on them, with labels:

~~~python
a = ???
b = ???

print("a + b =", a + b)
print("a - b =", a - b)
print("a * b =", a * b)
print("a / b =", a / b)
~~~

Replace `???` with your own numbers.  Run the file and verify the output.

Then change the values of `a` and `b` and run it again to see all results update.

Save your work.

## Exercise 4 (REPL exploration)

Open the Python REPL in the VS Code terminal (type `python3` and press Enter).

Try each of the following expressions in the REPL and observe the output:

~~~python
>>> 99 * 99
>>> 1000 / 8
>>> 2 * 2 * 2 * 2
>>> (10 + 5) * 3
>>> 17 - 4 * 2
~~~

For the last two expressions, think about the result before you press Enter — does Python give you what you expected?  Remember: multiplication happens before addition unless you add brackets.

Type `exit()` when you are done.
