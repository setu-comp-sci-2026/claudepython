# Challenges

In these challenges you will write slightly longer Python programs that combine `print`, arithmetic, and variables.  For each challenge, create a new Python file and save it as `lab01_challengeXX.py`.

## Challenge 1

A student scored the following marks in three tests:

- Test 1: 72
- Test 2: 85
- Test 3: 91

Create a new Python file and define three variables — `test1`, `test2`, and `test3` — with the scores above.

Then write code that:

1. Prints each individual score with a label (e.g. `"Test 1: 72"`)
2. Calculates and prints the **total** of all three scores
3. Calculates and prints the **average** score (total divided by 3)

Expected output:

~~~
Test 1: 72
Test 2: 85
Test 3: 91
Total: 248
Average: 82.666...
~~~

Save your work.

## Challenge 2

In this challenge, extend Challenge 1.

Create a new Python file and copy your Challenge 1 solution into it.

This time, add a fourth variable `bonus` and set it to `5`.  Then:

1. Print each original score **plus the bonus**, with a label (e.g. `"Test 1 with bonus: 77"`)
2. Recalculate and print the new total (original total + bonus × 3)
3. Recalculate and print the new average

Run the file.  Then try changing the value of `bonus` to `10` and run it again — all the results should update automatically.

Save your work.

## Challenge 3

A shop sells three items:

- Item A costs €12
- Item B costs €7
- Item C costs €20

Create a new Python file and define variables for each price.  Then write code that:

1. Prints the price of each item with a label
2. Calculates and prints the **total cost** of buying one of each item
3. Calculates and prints the cost of buying **two of item A, one of item B, and three of item C**

Label each printed result clearly so the output is easy to read.

Save your work.

## Challenge 4

Create your own Python program using variables and arithmetic.  Choose a topic that is meaningful to you — for example:

- distances between cities
- daily calorie targets
- sports scores
- conversion between currencies (e.g. multiply euro by 1.09 to get dollars)

Define at least three variables, perform at least three calculations, and print each result with a descriptive label.

Save your work.
