# Step 4 — Using Fixtures

## 4.1 — Shared fixtures in `conftest.py`

Create `tests/conftest.py`:

```python
import pytest
from src.bank_account import BankAccount
from src.product import Product

@pytest.fixture
def account():
    return BankAccount("Alice", 100.0)

@pytest.fixture
def empty_account():
    return BankAccount("Bob", 0.0)

@pytest.fixture
def apple():
    return Product("Apple", 1.99, 101)

@pytest.fixture
def bread():
    return Product("Bread", 2.50, 102)
```

Now these fixtures are available to *all* test files without imports.

## 4.2 — Fixture using another fixture

```python
# In conftest.py
from src.shop import Shop

@pytest.fixture
def populated_shop(apple, bread):
    shop = Shop("Test Shop")
    shop.add_product(apple)
    shop.add_product(bread)
    return shop
```

## 4.3 — Test using `populated_shop`

```python
# tests/test_shop.py
def test_shop_count(populated_shop):
    assert len(populated_shop.get_all_products()) == 2

def test_shop_find(populated_shop):
    p = populated_shop.find_by_name("Apple")
    assert p is not None
    assert p.get_price() == 1.99
```
