# Lab 13 — Dictionaries, Sets and Testing

## Objectives

By the end of this lab you will be able to:

- Create and manipulate Python `dict` and `set` objects
- Use dict comprehensions and set operations
- Write pytest unit tests following naming conventions
- Use `assert` statements to verify method behaviour
- Use `@pytest.fixture` to share setup code across tests
- Use `pytest.raises` to test that exceptions are raised correctly
- Use `@pytest.mark.parametrize` to test multiple inputs

**Create a folder `lab13/`** with subfolders `src/` and `tests/`.
