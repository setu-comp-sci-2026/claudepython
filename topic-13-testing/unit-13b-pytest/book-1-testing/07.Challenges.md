# Challenges

## Challenge 1 — Full Test Suite for Shop App

Write comprehensive tests covering every method of `Product` and `Shop`. Aim for > 90% code coverage:

```bash
pip install pytest-cov
pytest --cov=src --cov-report=term-missing
```

Fix any missing coverage by adding tests for uncovered lines.

## Challenge 2 — TDD for a New Class

Using TDD (write tests first), implement a `Library` class that manages a collection of `Book` objects:
- `Book` has `title`, `author`, `isbn`, `available` (bool)
- `Library` has `add_book()`, `borrow_book(isbn)`, `return_book(isbn)`, `search_by_author(name)`, `available_books()` 

Write all tests first, then implement to make them pass.

## Challenge 3 — Coverage Report

1. Install `pytest-cov`
2. Run: `pytest --cov=src --cov-report=html`
3. Open `htmlcov/index.html` in your browser
4. Identify which lines are not covered
5. Write additional tests to bring coverage above 95%

Include a brief comment in each new test explaining which branch it covers.
