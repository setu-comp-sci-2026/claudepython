## Exercise 1 — Dict: Word Frequency Counter

Write a function and tests for it:

```python
def word_frequency(text: str) -> dict:
    """Return a dict of {word: count} for each word in text."""
    freq = {}
    for word in text.lower().split():
        freq[word] = freq.get(word, 0) + 1
    return freq
```

Write tests for: empty string, single word, repeated words, mixed case.

## Exercise 2 — Set: Common and Unique

```python
def common_elements(a: list, b: list) -> set:
    return set(a) & set(b)

def unique_to_first(a: list, b: list) -> set:
    return set(a) - set(b)
```

Write at least 4 tests for each function.
