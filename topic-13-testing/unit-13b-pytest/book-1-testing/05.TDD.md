# Step 5 — TDD Exercise

Write tests *first*, then implement the class to make them pass.

## 5.1 — Write the tests first

Create `tests/test_student.py`:

```python
import pytest
# from src.student import Student  ← uncomment after writing tests

def test_student_name():
    s = Student("Alice", "alice@setu.ie", "S12345")
    assert s.get_name() == "Alice"

def test_student_email():
    s = Student("Alice", "alice@setu.ie", "S12345")
    assert s.get_email() == "alice@setu.ie"

def test_student_id():
    s = Student("Alice", "alice@setu.ie", "S12345")
    assert s.get_student_id() == "S12345"

def test_add_grade():
    s = Student("Alice", "alice@setu.ie", "S12345")
    s.add_grade("Python", 85)
    assert s.get_grade("Python") == 85

def test_average_grade():
    s = Student("Alice", "alice@setu.ie", "S12345")
    s.add_grade("Python", 80)
    s.add_grade("Maths", 90)
    assert s.average_grade() == 85.0

def test_no_grades_average():
    s = Student("Alice", "alice@setu.ie", "S12345")
    assert s.average_grade() == 0.0
```

## 5.2 — Run the tests (all fail — Red)

```bash
pytest tests/test_student.py -v
```

Expected: all FAILED.

## 5.3 — Implement to make them pass (Green)

Create `src/student.py` with a `Student` class that passes all the above tests.

## 5.4 — Refactor

Once all tests pass, clean up the implementation (better variable names, add docstrings) and run tests again to confirm nothing broke.
