# Nested `if` Statements

You can place `if` statements inside other `if` statements. This is called **nesting**.

## When to Use Nesting

Use nested `if` when a second decision only makes sense after the first condition is already `True`.

## Step 7 — Nested if Example

Create `lab02_step07.py`:

```python
username = input("Enter username: ")
password = input("Enter password: ")

if username == "admin":
    if password == "secret123":
        print("Login successful. Welcome, admin!")
    else:
        print("Wrong password.")
else:
    print("Unknown username.")
```

Test with:
- username: `admin`, password: `secret123` → Login successful
- username: `admin`, password: `wrong` → Wrong password
- username: `guest`, password: `anything` → Unknown username

## A Caution on Deep Nesting

Deeply nested `if` statements become hard to read. Often you can replace them with `and`:

```python
if username == "admin" and password == "secret123":
    print("Login successful. Welcome, admin!")
elif username != "admin":
    print("Unknown username.")
else:
    print("Wrong password.")
```

Which version do you find easier to read?
