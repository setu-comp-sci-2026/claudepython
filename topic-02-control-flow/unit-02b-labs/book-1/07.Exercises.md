# Exercises

These exercises are based on the material covered in the previous steps. For each exercise, create a new `.py` file named `lab02_exNN.py`.

## Exercise 1 — Odd or Even

Write a program that asks the user to enter a number and prints whether it is **odd** or **even**.

Hint: use the modulo operator `%`. A number is even if `number % 2 == 0`.

Expected output examples:
```
Enter a number: 7
7 is odd.

Enter a number: 12
12 is even.
```

## Exercise 2 — BMI Calculator

Write a program that:
1. Asks the user for their weight (kg) and height (m)
2. Calculates BMI: `bmi = weight / (height ** 2)`
3. Prints the BMI category:
   - BMI < 18.5 → Underweight
   - 18.5 ≤ BMI < 25 → Normal weight
   - 25 ≤ BMI < 30 → Overweight
   - BMI ≥ 30 → Obese

## Exercise 3 — Simple Calculator

Write a program that:
1. Asks the user for two numbers and an operator (`+`, `-`, `*`, `/`)
2. Performs the calculation and prints the result
3. Handles division by zero with an appropriate error message

## Exercise 4 — Traffic Light

Write a program that asks the user to enter a traffic light colour (`red`, `amber`, or `green`) and prints the appropriate instruction:
- `red` → Stop
- `amber` → Prepare to stop
- `green` → Go
- anything else → Invalid colour
