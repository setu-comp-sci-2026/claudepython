# The `if-elif-else` Statement

When you have **more than two** possible outcomes, use `elif` (short for "else if") to chain conditions.

## Syntax

```python
if condition1:
    # runs when condition1 is True
elif condition2:
    # runs when condition1 is False AND condition2 is True
elif condition3:
    # runs when condition1 and condition2 are False AND condition3 is True
else:
    # runs when ALL conditions above are False
```

Python checks conditions **in order** and stops at the first `True` one.

## Step 4 — Grading System

Create a new file `lab02_step04.py`:

```python
mark = int(input("Enter your mark (0-100): "))

if mark >= 70:
    grade = "A"
elif mark >= 60:
    grade = "B"
elif mark >= 50:
    grade = "C"
elif mark >= 40:
    grade = "D"
else:
    grade = "F"

print(f"Your grade is: {grade}")
```

Test with the following values and verify you get the correct grade:
- 85 → A
- 65 → B
- 52 → C
- 41 → D
- 30 → F

## Why Order Matters

Try swapping the first two conditions (put `mark >= 60` before `mark >= 70`). What happens when you enter 85?

This shows why the order of `elif` conditions is critical.
