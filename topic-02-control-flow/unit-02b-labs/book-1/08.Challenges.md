# Challenges

These challenges require a bit more thought. For each, create a new `.py` file named `lab02_chNN.py`.

## Challenge 1 — FizzBuzz

Write a program that asks the user for a number and:
- Prints `FizzBuzz` if the number is divisible by both 3 and 5
- Prints `Fizz` if the number is divisible by 3 only
- Prints `Buzz` if the number is divisible by 5 only
- Prints the number itself otherwise

Hint: check the `FizzBuzz` condition first — order matters!

## Challenge 2 — Triangle Classifier

Write a program that:
1. Asks the user for three side lengths of a triangle
2. First checks if the sides can form a valid triangle (the sum of any two sides must be greater than the third)
3. If valid, classifies it as:
   - **Equilateral**: all three sides equal
   - **Isosceles**: exactly two sides equal
   - **Scalene**: no sides equal

## Challenge 3 — Leap Year

Write a program that asks for a year and determines if it is a leap year. A leap year is:
- Divisible by 4, **AND**
- NOT divisible by 100, **unless** it is also divisible by 400

Examples: 2000 → leap year, 1900 → not a leap year, 2024 → leap year.

## Challenge 4 — Password Strength Checker

Write a program that rates a password entered by the user as **Weak**, **Medium**, or **Strong**:
- **Weak**: fewer than 6 characters
- **Medium**: 6–11 characters
- **Strong**: 12 or more characters

Then extend it: for **Medium** or **Strong**, also require at least one digit (hint: `any(c.isdigit() for c in password)`).
