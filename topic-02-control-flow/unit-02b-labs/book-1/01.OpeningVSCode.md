## Creating a Python File

Inside VS Code, create a new Python file:

1. Click **File → New File**
2. Save immediately with **File → Save As...**
3. Name it `lab02_step02.py`

VS Code will auto-detect the `.py` extension and switch to Python mode (shown in the bottom status bar). If prompted to select a Python interpreter, choose **Python 3**.

## Running Your Code

To run a Python file in VS Code:

- Right-click anywhere in the editor and choose **Run Python File in Terminal**
- Or press `Ctrl+F5` (Windows/Linux) / `Cmd+F5` (macOS)

The **Terminal** panel opens at the bottom of VS Code and shows your output.

## The Python Interactive Terminal (REPL)

You can also experiment interactively. Open the terminal (**View → Terminal**) and type:

```
python3
```

Then type Python expressions line by line:

```python
>>> 2 + 2
4
>>> name = "Python"
>>> print(f"Hello, {name}!")
Hello, Python!
```

Type `exit()` to leave the interactive mode.
