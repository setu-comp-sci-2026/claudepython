# The `if-else` Statement

The `if-else` statement handles both cases — when the condition is `True` **and** when it is `False`.

## Syntax

```python
if condition:
    # runs when condition is True
else:
    # runs when condition is False
```

## Step 2 — Adding an `else` Clause

Create a new file `lab02_step02.py` and enter:

```python
age = 15

if age >= 18:
    print("You are an adult.")
    print("You are old enough to vote.")
else:
    print("You are a minor.")
    print("You cannot vote yet.")
```

Run with `age = 15`. You should see:

```
You are a minor.
You cannot vote yet.
```

Try different values of `age` — what is the boundary value where the output changes?

## Step 3 — Asking for User Input

Modify your code to ask the user for their age instead of hard-coding it:

```python
age = int(input("Enter your age: "))

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")
```

`input()` returns a string, so `int()` converts it to an integer. Run the program and enter different ages.
