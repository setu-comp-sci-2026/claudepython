# The `if` Statement

The `if` statement lets your program make decisions — it runs a block of code only when a condition is `True`.

## Syntax

```python
if condition:
    # code to run when condition is True
```

**Important:** Python uses **indentation** (4 spaces or 1 tab) to define the block. There are no curly braces like in Java.

## Step 1 — Your First `if` Statement

Create a new file `lab02_step02.py` in VS Code and enter:

```python
age = 20

if age >= 18:
    print("You are an adult.")
    print("You are old enough to vote.")
```

Run the code. You should see:

```
You are an adult.
You are old enough to vote.
```

Now change `age = 20` to `age = 15` and run again. What do you notice?

## Why No Output?

When `age = 15`, the condition `age >= 18` is `False`, so the indented block is **skipped entirely**. The program simply ends with no output.
