# Opening VS Code and Creating a Python File

## Opening Visual Studio Code

Launch **Visual Studio Code** from your applications menu or taskbar.

Once open, create a new folder for your lab work. You can do this via:

- **File → Open Folder** and create/select a folder called `lab02`

## Creating a Python File

Inside VS Code, create a new file:

1. Click **File → New File**
2. Save it immediately with **File → Save As...**
3. Name it `lab02_step01.py`

Make sure VS Code shows **Python** in the bottom status bar (it auto-detects `.py` files). If prompted to select a Python interpreter, choose Python 3.

## Running Your Code

To run a Python file in VS Code:

- Right-click in the editor and choose **Run Python File in Terminal**
- Or press `Ctrl+F5` (Windows/Linux) / `Cmd+F5` (macOS)

The output appears in the **Terminal** panel at the bottom of VS Code.
