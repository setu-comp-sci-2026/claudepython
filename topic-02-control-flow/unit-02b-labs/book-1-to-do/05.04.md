# Relational and Logical Operators

## Relational Operators

These compare two values and return `True` or `False`:

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | Equal to | `age == 18` |
| `!=` | Not equal to | `age != 18` |
| `>` | Greater than | `age > 18` |
| `<` | Less than | `age < 18` |
| `>=` | Greater than or equal to | `age >= 18` |
| `<=` | Less than or equal to | `age <= 18` |

## Logical Operators

These combine multiple conditions:

| Operator | Meaning | Example |
|----------|---------|---------|
| `and` | Both must be True | `age >= 18 and age < 65` |
| `or` | At least one must be True | `age < 5 or age > 65` |
| `not` | Inverts the condition | `not (age >= 18)` |

## Step 5 — Using Logical Operators

Create `lab02_step05.py`:

```python
temperature = float(input("Enter the temperature (°C): "))

if temperature >= 20 and temperature <= 30:
    print("Comfortable temperature.")
elif temperature > 30:
    print("Too hot!")
elif temperature < 0:
    print("Freezing!")
else:
    print("A bit chilly.")
```
