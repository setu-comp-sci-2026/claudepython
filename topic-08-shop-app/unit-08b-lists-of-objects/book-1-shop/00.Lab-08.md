# Lab 08 — Shop Application

## Objectives

By the end of this lab you will be able to:

- Implement a `Product` class with private attributes, getters, setters, and `__str__`
- Add validation using `ValueError` and call setters from `__init__`
- Implement a `Shop` class that manages a list of `Product` objects
- Write `add_product()`, `find_by_name()`, `remove_product()`, and `total_value()` methods
- Write a driver (`main.py`) that exercises all of the above
- Handle exceptions with `try/except` in the driver

---

**File structure for this lab:**

```
lab08/
├── product.py
├── shop.py
└── driver.py
```

Create a folder called `lab08` inside your `labs` folder in VS Code.
