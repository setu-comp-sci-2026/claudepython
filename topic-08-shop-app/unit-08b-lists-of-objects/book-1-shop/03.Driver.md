# Step 3 — Writing the Driver

Create `driver.py`. This file imports and uses the `Product` and `Shop` classes.

## 3.1 — Imports and setup

```python
from product import Product
from shop import Shop

def main():
    my_shop = Shop("Green Grocer")

    my_shop.add_product(Product("Apple",  1.99, 101))
    my_shop.add_product(Product("Bread",  2.50, 102))
    my_shop.add_product(Product("Milk",   1.20, 103))
    my_shop.add_product(Product("Butter", 3.00, 104))

    print(my_shop)
    my_shop.display_all()
    print(f"\nTotal value: €{my_shop.total_value():.2f}")

if __name__ == "__main__":
    main()
```
