## Challenge 1 — Discount System

Add a `apply_discount(percent: float)` method to `Shop` that reduces every product's price by the given percentage:

```python
def apply_discount(self, percent: float):
    if not (0 < percent < 100):
        raise ValueError("Discount must be between 0 and 100")
    for p in self.__products:
        new_price = p.get_price() * (1 - percent / 100)
        p.set_price(round(new_price, 2))
```

Test: apply a 10% discount, then display all products to confirm new prices.

## Challenge 2 — Stock Management

Add `quantity` to `Product` (as in Exercise 1). Then add these methods to `Shop`:

```python
def sell(self, name: str, amount: int) -> bool:
    p = self.find_by_name(name)
    if p is None:
        raise ValueError(f"Product '{name}' not found")
    if p.get_quantity() < amount:
        raise ValueError(f"Not enough stock: have {p.get_quantity()}, need {amount}")
    p.set_quantity(p.get_quantity() - amount)
    return True

def restock(self, name: str, amount: int):
    p = self.find_by_name(name)
    if p is None:
        raise ValueError(f"Product '{name}' not found")
    p.set_quantity(p.get_quantity() + amount)

def out_of_stock(self) -> list:
    return [p for p in self.__products if p.get_quantity() == 0]
```

## Challenge 3 — Export to File

Add a method to write all products to a text file:

```python
def export_to_file(self, filename: str):
    with open(filename, "w") as f:
        f.write(f"Shop: {self.__name}\n")
        f.write("=" * 40 + "\n")
        for p in self.__products:
            f.write(f"{p}\n")
        f.write("=" * 40 + "\n")
        f.write(f"Total value: €{self.total_value():.2f}\n")
```

Call `my_shop.export_to_file("shop_report.txt")` and open the file to verify.
