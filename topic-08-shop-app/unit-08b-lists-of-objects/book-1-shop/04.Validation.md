# Step 4 — Adding Validation

Update `product.py` to validate inputs.

## 4.1 — Update `set_name()`

```python
    def set_name(self, name: str):
        name = name.strip()
        if not name:
            raise ValueError("Product name cannot be empty")
        self.__name = name
```

## 4.2 — Update `set_price()`

```python
    def set_price(self, price: float):
        if price <= 0:
            raise ValueError(
                f"Price must be greater than 0, got {price}"
            )
        self.__price = price
```

## 4.3 — Call setters from `__init__`

```python
    def __init__(self, name: str, price: float, product_id: int):
        self.__product_id = product_id
        self.__name = ""
        self.__price = 0.0
        self.set_name(name)    # validates name
        self.set_price(price)  # validates price
```

## 4.4 — Handle errors in the driver

Update `driver.py`:

```python
def safe_add(shop, name, price, pid):
    try:
        shop.add_product(Product(name, price, pid))
        print(f"Added: {name}")
    except ValueError as e:
        print(f"  [SKIPPED] {e}")

def main():
    my_shop = Shop("Green Grocer")
    safe_add(my_shop, "Apple",  1.99, 101)
    safe_add(my_shop, "",       2.50, 102)   # bad name
    safe_add(my_shop, "Milk",  -1.20, 103)   # bad price
    safe_add(my_shop, "Butter", 3.00, 104)
    my_shop.display_all()
```

Run it and observe which products are skipped.
