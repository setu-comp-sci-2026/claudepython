# Step 2 — Implementing the Shop Class

Create a new file called `shop.py`.

## 2.1 — Constructor with an empty list

```python
from product import Product

class Shop:
    def __init__(self, name: str):
        self.__name = name
        self.__products = []

    def get_name(self) -> str:
        return self.__name

    def get_all_products(self) -> list:
        return self.__products

    def __str__(self) -> str:
        return f"Shop: {self.__name} ({len(self.__products)} products)"
```

## 2.2 — `add_product()`

```python
    def add_product(self, product: Product):
        self.__products.append(product)
```

## 2.3 — `display_all()`

```python
    def display_all(self):
        if not self.__products:
            print("The shop is empty.")
            return
        print(f"\n--- {self.__name} ---")
        for p in self.__products:
            print(f"  {p}")
```

## 2.4 — `find_by_name()`

```python
    def find_by_name(self, name: str):
        for p in self.__products:
            if p.get_name().lower() == name.strip().lower():
                return p
        return None
```

## 2.5 — `remove_product()`

```python
    def remove_product(self, name: str) -> bool:
        p = self.find_by_name(name)
        if p:
            self.__products.remove(p)
            return True
        return False
```

## 2.6 — `total_value()`

```python
    def total_value(self) -> float:
        return sum(p.get_price() for p in self.__products)
```
