## Exercise 2 — Search by ID

Add a method to `Shop`:

```python
def find_by_id(self, product_id: int):
    for p in self.__products:
        if p.get_product_id() == product_id:
            return p
    return None
```

## Exercise 3 — Shop Statistics

Add these methods to `Shop`:

```python
def most_expensive(self):
    if not self.__products:
        return None
    return max(self.__products, key=lambda p: p.get_price())

def cheapest(self):
    if not self.__products:
        return None
    return min(self.__products, key=lambda p: p.get_price())

def average_price(self) -> float:
    if not self.__products:
        return 0.0
    return self.total_value() / len(self.__products)
```

Print all three statistics in the driver.

## Exercise 4 — Categories

Add a `category` attribute (str) to `Product`. Then add a method to `Shop`:

```python
def get_by_category(self, category: str) -> list:
    return [p for p in self.__products
            if p.get_category().lower() == category.lower()]
```

Add products with categories `"fruit"`, `"dairy"`, `"bakery"` and test the filter.
