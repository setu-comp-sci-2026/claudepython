# Step 1 — Implementing the Product Class

Create a new file called `product.py`.

## 1.1 — Basic structure

```python
class Product:
    def __init__(self, name: str, price: float, product_id: int):
        self.__name = name
        self.__price = price
        self.__product_id = product_id
```

## 1.2 — Add getters and setters

```python
    def get_name(self) -> str:
        return self.__name

    def set_name(self, name: str):
        self.__name = name

    def get_price(self) -> float:
        return self.__price

    def set_price(self, price: float):
        self.__price = price

    def get_product_id(self) -> int:
        return self.__product_id
```

## 1.3 — Add `__str__`

```python
    def __str__(self) -> str:
        return (f"Product [{self.__product_id}]: "
                f"{self.__name} — €{self.__price:.2f}")
```

## 1.4 — Quick test

In `driver.py` (just temporarily):
```python
from product import Product

```
