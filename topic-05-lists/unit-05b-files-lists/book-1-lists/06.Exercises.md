## Exercise 2 — Statistics Calculator

Ask the user to enter numbers one at a time (stop when they enter `done`). Then print:
- Count, sum, mean, median, mode, min, max
- Values sorted ascending and descending
- How many are above average

```python
numbers = []
print("Enter numbers (type 'done' to finish):")
while True:
    entry = input("> ")
    if entry.lower() == "done":
        break
    try:
        numbers.append(float(entry))
    except ValueError:
        print("Please enter a number or 'done'")
```

## Exercise 3 — Word Frequency from File

Read a text file and count how often each word appears. Write the results to a new file sorted by frequency (most common first).

```python
def count_words(filename):
    word_count = {}
    with open(filename, "r") as f:
        for line in f:
            for word in line.lower().split():
                # Remove punctuation from word
                clean = "".join(c for c in word if c.isalpha())
                if clean:
                    word_count[clean] = word_count.get(clean, 0) + 1
    return word_count
```
