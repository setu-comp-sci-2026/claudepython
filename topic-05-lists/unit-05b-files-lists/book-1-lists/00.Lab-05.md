# Lab 05 — Lists and File Handling

## Objectives

By the end of this lab you will be able to:

- Create and manipulate Python **lists** using indexing and slicing
- Use common **list methods** (append, remove, sort, pop, etc.)
- Iterate over lists using **for loops** and **enumerate()**
- Write **list comprehensions** for concise data transformation
- **Read** a text file line by line using `open()` and the `with` statement
- **Write** data to a text file
- Read and write **CSV files** using the `csv` module

## Setup

Create a new folder `lab05` and a file `lists.py` in VS Code.

For the file I/O sections, you will also create sample text files to read.
