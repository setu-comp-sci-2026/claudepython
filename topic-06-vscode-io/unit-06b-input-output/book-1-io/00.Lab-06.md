# Lab 06 — VS Code & Input/Output

## Objectives

By the end of this lab you will be able to:

- Use VS Code's **debugger** to pause execution, inspect variables, and step through code
- Use `input()` and understand that it always returns a **string**
- Apply **type conversion** (`int()`, `float()`, `bool()`) to user input
- Validate input using **try/except** and loops
- Use **f-strings** with format specifiers (decimal places, alignment, thousands separator, percentage)
- Print formatted **tables** with column alignment

## Setup

Create a new folder `lab06` and a file `io_practice.py` in VS Code.
