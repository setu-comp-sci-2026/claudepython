# Exercises

## Exercise 1 — BMI Calculator

Write a program that:
1. Asks for the user's name, weight (kg), and height (m)
2. Validates all inputs (weight > 0, height > 0)
3. Calculates BMI = weight / height²
4. Prints a formatted result including BMI category

BMI categories: Underweight (<18.5), Normal (18.5-24.9), Overweight (25-29.9), Obese (>=30)

Format BMI to 1 decimal place. Show the category on the same line.

## Exercise 3 — Receipt Printer

1. Lets the user enter items (name + price) until they type "done"
2. Applies a 10% discount if total > €50
3. Adds 23% VAT to the discounted total
4. Prints a formatted receipt

```

--------------------------
Coffee             €3.50

Cake               €4.25
--------------------------

Discount (10%):   -€0.00
VAT (23%):         €3.38
--------------------------
TOTAL:            €18.08
```
