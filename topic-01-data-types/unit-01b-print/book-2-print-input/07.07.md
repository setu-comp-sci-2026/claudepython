# Common Errors

Working through the previous steps you may have encountered some errors.  This step deliberately introduces common mistakes with `print()` and `input()` so you become familiar with the error messages and how to fix them.

Create a new Python file in VS Code for this step.


## Missing quotes around a string

~~~python
print(Hello, World!)
~~~

Python sees `Hello` as a variable name and raises a `SyntaxError` because it cannot find a variable with that name.  Fix: wrap the string in quotes.


## Mixing strings and numbers without conversion

~~~python
age = 20
print("I am " + age + " years old")
~~~

This raises a `TypeError` because you cannot concatenate a string and an integer with `+`.  Fix it in either of two ways:

~~~python
# Option 1: convert the number to a string
print("I am " + str(age) + " years old")

# Option 2: use an f-string (preferred)
print(f"I am {age} years old")
~~~


## Forgetting the f prefix on an f-string

~~~python
name = "Alice"
print("Hello, {name}!")
~~~

Without the `f` prefix the `{}` is treated as literal text, so the output is:

~~~
Hello, {name}!
~~~

Fix: add `f` before the opening quote — `f"Hello, {name}!"`.


## Doing arithmetic on input() without converting

~~~python
num = input("Enter a number: ")
print(num * 2)
~~~

If the user types `5`, the output is `55` instead of `10` — because `input()` returns the string `"5"` and multiplying a string by 2 repeats it.

Fix:

~~~python
num = int(input("Enter a number: "))
print(num * 2)
~~~


## Entering text when a number is expected

~~~python
age = int(input("Enter your age: "))
~~~

If the user types `twenty` instead of `20`, Python raises a `ValueError`:

~~~
ValueError: invalid literal for int() with base 10: 'twenty'
~~~

You cannot convert a word to an integer.  The user must type a valid whole number.
