# Printing Multiple Values

You can pass more than one value to `print()` by separating them with commas.  Python automatically puts a space between each value.

Create a new Python file and enter the following code:

~~~python
name = "Alice"
age = 20
city = "Waterford"

print("Name:", name)
print("Age:", age)
print("Name:", name, "Age:", age, "City:", city)
~~~

Run it and you should see:

~~~
Name: Alice
Age: 20
Name: Alice Age: 20 City: Waterford
~~~


## Changing the separator with sep=

The default separator between values is a space.  You can change it using the `sep=` keyword argument:

~~~python
print("Alice", "Bob", "Carol", sep=", ")
print(2024, 6, 18, sep="-")
print("one", "two", "three", sep=" | ")
~~~

Output:

~~~
Alice, Bob, Carol
2024-6-18
one | two | three
~~~

Try changing the `sep=` value to something else and observe the result.


## Staying on the same line with end=

By default, `print()` adds a newline (`\n`) at the end.  Use `end=` to change this:

~~~python
print("Loading", end="")
print("...")

print("First", end=" ")
print("Second", end=" ")
print("Third")
~~~

Output:

~~~
Loading...
First Second Third
~~~

The first two lines are joined because `end=""` replaces the newline with nothing.
