# Formatted Output with f-strings

f-strings are the recommended way to build output strings in Python.  You prefix a string with `f` and then place any variable or expression inside `{}` — Python evaluates it and inserts the result directly into the string.

Create a new Python file and try the following:

~~~python
name = "Alice"
age = 20

print(f"Hello, {name}!")
print(f"Next year you will be {age + 1}")
~~~

Output:

~~~
Hello, Alice!
Next year you will be 21
~~~

Notice the `f` immediately before the opening quote.  Without it, `{name}` would be printed literally as the text `{name}` rather than the value of the variable.


## Formatting numbers

You can control how numbers appear by adding a format specifier after a colon inside `{}`:

~~~python
price = 9.5
pi = 3.14159
score = 0.756

print(f"Price:  £{price:.2f}")
print(f"Pi ≈ {pi:.4f}")
print(f"Score:  {score:.0%}")
~~~

Output:

~~~
Price:  £9.50
Pi ≈ 3.1416
Score:  76%
~~~

The format specifiers used above are:

- `:.2f` — float with 2 decimal places
- `:.4f` — float with 4 decimal places
- `:.0%` — percentage with no decimal places


## Why use f-strings?

Compare these two ways of building the same output string:

~~~python
name = "Bob"
age = 25

# Using + (requires str() conversion)
print("Name: " + name + ", Age: " + str(age))

# Using an f-string (cleaner and easier to read)
print(f"Name: {name}, Age: {age}")
~~~

Both produce the same result, but the f-string version is easier to read and write.  You will see f-strings used throughout the rest of the course.
