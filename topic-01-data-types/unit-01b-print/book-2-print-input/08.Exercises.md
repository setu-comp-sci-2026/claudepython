# Exercises

The exercises below are based on the material covered in this lab and in the presentation slides.

For each exercise, create a new Python file in VS Code.


## Exercise 1 (print with multiple values)

Create a new Python file and declare the following variables:

~~~python
city    = "Waterford"
country = "Ireland"
pop     = 56000
~~~

Write three `print()` statements that produce **exactly** this output (no f-strings — use comma-separated values):

~~~
City: Waterford
Country: Ireland
Waterford, Ireland (pop: 56000)
~~~

Save your work.


## Exercise 2 (sep= and end=)

Create a new Python file and use **only** `print()` with `sep=` and/or `end=` to produce the following output:

~~~
2024-06-18
Mon | Tue | Wed | Thu | Fri
Start...Middle...End
~~~

Each line must come from a single `print()` call.

Save your work.


## Exercise 3 (f-strings)

Create a new Python file and declare the following variables:

~~~python
product = "Coffee"
price   = 3.5
qty     = 4
~~~

Use f-strings to produce **exactly** this output:

~~~
Item:     Coffee
Price:    £3.50
Quantity: 4
Total:    £14.00
~~~

Hint: the total should be calculated inside the f-string expression — do not create an extra variable for it.

Save your work.


## Exercise 4 (input and arithmetic)

Create a new Python file.  Ask the user for two numbers (as floats) and print their sum, difference, product, and quotient, each on its own line and formatted to 2 decimal places.

Example run:

~~~
Enter first number:  8
Enter second number: 3
Sum:        11.00
Difference: 5.00
Product:    24.00
Quotient:   2.67
~~~

Save your work.
