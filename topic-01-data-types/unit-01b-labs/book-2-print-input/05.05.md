# The input() Function

The `input()` function pauses the program and waits for the user to type something and press Enter.  Whatever the user types is returned as the result and can be stored in a variable.

The text you pass inside the brackets is the *prompt* — it is displayed to the user to tell them what to type.

Create a new Python file and try the following:

~~~python
name = input("What is your name? ")
print(f"Hello, {name}!")
~~~

When you run this, the terminal will display:

~~~
What is your name? 
~~~

Type your name and press Enter.  You should then see:

~~~
What is your name? Alice
Hello, Alice!
~~~


## Prompts with a trailing space

Notice the space at the end of the prompt string:

~~~python
name = input("What is your name? ")
~~~

This is a common convention — the space separates the prompt text from whatever the user types, making it easier to read.  Try removing the space and observe the difference.


## Storing and reusing input

You can ask for several pieces of input and use them all:

~~~python
first_name = input("First name: ")
last_name  = input("Last name:  ")

print(f"Welcome, {first_name} {last_name}!")
~~~

Run the program, enter a first and last name when prompted, and confirm the greeting appears correctly.
