# Challenges

For each challenge, create a new Python file in VS Code.


## Challenge 1

Write a program that asks the user for their name and age, then prints a short profile using an f-string.  The age next year should be calculated automatically.

Example run:

~~~
Enter your name: Alice
Enter your age:  20
---------------------
Name:      Alice
Age:       20
Next year: 21
---------------------
~~~

The dividing lines (`-----`) must be exactly 21 dashes.

Save your work.


## Challenge 2

Write a program that acts as a simple receipt printer.  Ask the user for:

- a product name
- a price per unit (float)
- a quantity (integer)

Then print a formatted receipt like this:

~~~
=============================
         RECEIPT
=============================
Item:     Coffee
Price:    £3.50
Qty:      4
-----------------------------
Total:    £14.00
=============================
~~~

All number values should be formatted to 2 decimal places.

Save your work.


## Challenge 3

Write a program that converts a temperature entered by the user from Celsius to both Fahrenheit and Kelvin.

The formulas are:

- Fahrenheit = (Celsius × 9/5) + 32
- Kelvin = Celsius + 273.15

Example run:

~~~
Enter temperature in Celsius: 100
100.00 °C  =  212.00 °F
100.00 °C  =  373.15 K
~~~

All values should be formatted to 2 decimal places.

Save your work.


## Challenge 4

Write a program that asks the user for their first name, last name, and year of birth, then displays a formatted summary that includes their initials and their age (calculated from the current year, 2024).

Example run:

~~~
First name:    Alice
Last name:     Murphy
Year of birth: 2004
----------------------------
Full name: Alice Murphy
Initials:  A.M.
Age:       20
----------------------------
~~~

Hint: to get the first character of a string, use indexing — `name[0]`.

Save your work.
