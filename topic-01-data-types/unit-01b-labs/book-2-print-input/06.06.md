# input() Always Returns a String

This is one of the most important things to understand about `input()`: **it always returns a string**, even when the user types a number.

Create a new Python file and try the following:

~~~python
age = input("Enter your age: ")
print(age)
print(type(age))
~~~

When you run this and type `20`, you will see:

~~~
Enter your age: 20
20
<class 'str'>
~~~

Even though `20` looks like a number, Python stored it as the string `"20"`.  This can cause problems if you try to do arithmetic with it:

~~~python
age = input("Enter your age: ")
next_year = age + 1
print(next_year)
~~~

Run this code and observe the error:

~~~
TypeError: can only concatenate str (not "int") to str
~~~

Python cannot add an integer to a string.


## Converting input to a number

Use `int()` or `float()` to convert the string returned by `input()` to a number:

~~~python
age    = int(input("Enter your age: "))
height = float(input("Enter your height in metres: "))

print(f"Age:    {age}")
print(f"Height: {height:.2f} m")
print(type(age))
print(type(height))
~~~

Output:

~~~
Enter your age: 20
Enter your height in metres: 1.75
Age:    20
Height: 1.75 m
<class 'int'>
<class 'float'>
~~~

Now the variables hold actual numbers and you can do arithmetic with them:

~~~python
age = int(input("Enter your age: "))
print(f"In 10 years you will be {age + 10}")
~~~
