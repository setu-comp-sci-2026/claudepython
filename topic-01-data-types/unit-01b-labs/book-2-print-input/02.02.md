# The print() Function

The `print()` function is the most basic way to display output in Python.  Every time you call `print()`, the output appears in the terminal and a new line is started automatically.

In VS Code, create a new Python file (use **File > New File** and save it with a `.py` extension).  Enter the following code and run it:

~~~python
print("Hello, World!")
print("My name is Python")
print(42)
print(3.14)
print(10 + 5)
~~~

You should see five lines of output in the terminal:

~~~
Hello, World!
My name is Python
42
3.14
15
~~~

Notice that:

- Strings must be enclosed in quotes (single `'` or double `"`)
- Numbers and expressions are printed directly — no quotes needed
- Each `print()` call starts on a new line


## Printing variables

You can also print the value of a variable:

~~~python
name = "Alice"
age = 20

print(name)
print(age)
~~~

Run the code and confirm the values appear in the terminal.

Save your work using the naming convention: *labXX_stepYY.py*, where *XX* is the lab number and *YY* is the step number.
