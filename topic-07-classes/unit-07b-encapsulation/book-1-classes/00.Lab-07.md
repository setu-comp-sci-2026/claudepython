# Lab 07 — Classes and Objects

## Objectives

By the end of this lab you will be able to:

- Define a **class** with `__init__`, instance variables, and methods
- Create **objects** (instances) from a class
- Implement `__str__` for readable output
- Add **validation** to `__init__` and setters using `raise ValueError`
- Apply the **_ and __ naming convention** for private attributes
- Use the **@property** decorator to create validated attributes with attribute-style access
- Write basic **tests** for your classes using `assert`

## Setup

Create a new folder `lab07` and a file `classes.py` in VS Code.
