## Exercise 1 — Rectangle Class

Create a `Rectangle` class with:
- `width` and `height` properties (validated: must be positive numbers)
- Read-only computed properties: `area`, `perimeter`, `diagonal`
- Method `is_square()` — returns True if width == height
- Method `scale(factor)` — returns a new Rectangle scaled by factor
- `__str__` method

```python
# Test it:
r = Rectangle(4, 6)
print(r)                        # Rectangle(4 x 6)
print(f"Area: {r.area}")        # 24
print(f"Perimeter: {r.perimeter}")  # 20
print(f"Is square: {r.is_square()}")  # False

big = r.scale(3)
print(big)                      # Rectangle(12 x 18)

try:
    r2 = Rectangle(-1, 5)       # should raise ValueError
except ValueError as e:
    print(f"Caught: {e}")
```

## Exercise 3 — Library Book Class

Create a `Book` class representing a library book:
- Properties: `title`, `author`, `isbn` (read-only), `is_available`
- Methods: `check_out(borrower_name)` — marks as unavailable, records borrower
- `return_book()` — marks as available, clears borrower
- `__str__` — shows title, author, and availability status

```python
book = Book("Python Crash Course", "Eric Matthes", "978-1718502703")
print(book)                   # shows as available
book.check_out("Alice")
print(book)                   # shows as checked out by Alice
book.return_book()
print(book)                   # shows as available again

# Try checking out a book that's already out
book.check_out("Bob")
try:
    book.check_out("Carol")   # should raise an error
except Exception as e:
    print(f"Error: {e}")
```
