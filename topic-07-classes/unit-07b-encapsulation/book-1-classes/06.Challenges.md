## Challenge 1 — Contact Book

Build a contact book using two classes: `Contact` and `ContactBook`.

**Contact class:**
- Properties: `name`, `phone`, `email` (all validated)
- Phone: must be digits only, 7-15 characters
- Email: must contain `@` and a domain with `.`
- `__str__` showing all contact info

**ContactBook class:**
- Stores a list of `Contact` objects
- Methods:
  - `add(contact)` — add a contact (reject duplicate phone/email)
  - `remove(name)` — remove by name
  - `find(search)` — return contacts matching search in name, phone, or email
  - `list_all()` — print all contacts sorted by name
  - `save(filename)` — save all contacts to a CSV file
  - `load(filename)` — load contacts from a CSV file

```python
book = ContactBook()
book.add(Contact("Alice Murphy", "0851234567", "alice@example.com"))
book.add(Contact("Bob Kelly", "0877654321", "bob@example.com"))
book.list_all()
book.save("contacts.csv")

results = book.find("alice")
for c in results:
    print(c)
```

## Challenge 2 — Simple Bank System

Build a small banking system with:

**BankAccount class** (with full @property validation):
- Properties: `account_no`, `name`, `balance`, `account_type` ("savings"/"current")
- Methods: `deposit(amount)`, `withdraw(amount)`, `print_statement()`
- Savings accounts: cannot go below €0
- Current accounts: can go below €0 up to an overdraft limit (default €500)

**Bank class:**
- Stores multiple BankAccount objects in a dictionary (account_no → account)
- Methods:
  - `create_account(name, account_type, initial_balance)` — generates unique account number
  - `get_account(account_no)` — return account or raise KeyError
  - `transfer(from_no, to_no, amount)` — transfer between accounts
  - `total_deposits()` — total of all positive balances
  - `print_all_accounts()` — formatted table

## Challenge 3 — Product Catalogue

Build a product catalogue system:

**Product class:**
- Properties: `product_id` (read-only), `name`, `price`, `quantity_in_stock`
- Price must be >= 0; quantity must be >= 0
- Methods: `restock(quantity)`, `sell(quantity)` (raises error if insufficient stock)
- Computed property: `total_value` (price * quantity_in_stock)

**Catalogue class:**
- Stores products; supports add, remove, find by name or ID
- Method `low_stock(threshold=5)` — return products with quantity <= threshold
- Method `total_inventory_value()` — sum of all products' total_value
- Method `most_expensive(n=3)` — return the n most expensive products
- Save/load to CSV

```python
cat = Catalogue()
cat.add(Product("Laptop", 999.99, 10))
cat.add(Product("Mouse", 29.99, 50))
cat.add(Product("Keyboard", 79.99, 3))

print(f"Total value: €{cat.total_inventory_value():,.2f}")
print("Low stock items:")
for p in cat.low_stock(threshold=5):
    print(f"  {p.name}: {p.quantity_in_stock} remaining")
```
