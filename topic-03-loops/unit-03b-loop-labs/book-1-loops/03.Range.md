# The range() Function

`range()` generates a sequence of integers. It is the most common way to control a for loop with numbers.

## Three Forms of range()

| Form | Generates |
|------|-----------|
| `range(n)` | `0, 1, 2, ..., n-1` |
| `range(start, stop)` | `start, start+1, ..., stop-1` |
| `range(start, stop, step)` | `start, start+step, ..., < stop` |

## Step 1 — Basic range()

```python
# range(5) → 0, 1, 2, 3, 4
for i in range(5):
    print(i, end=" ")
print()

# range(1, 6) → 1, 2, 3, 4, 5
for i in range(1, 6):
    print(i, end=" ")
print()
```

## Step 2 — Stepping

```python
# Even numbers from 0 to 20
for n in range(0, 21, 2):
    print(n, end=" ")
print()

# Odd numbers from 1 to 19
for n in range(1, 20, 2):
    print(n, end=" ")
print()

# Multiples of 5
for n in range(5, 51, 5):
    print(n, end=" ")
print()
```

## Step 3 — Reversed Range

```python
# Count down from 10 to 1
for i in range(10, 0, -1):
    print(i, end=" ")
print("Go!")
```

You can also use `reversed()` with a range:

```python
for i in reversed(range(1, 6)):
    print(i, end=" ")
print()
```

## Step 4 — Using range() with len()

When you need the index to modify a list, use `range(len(list))`:

```python
prices = [10.99, 25.50, 8.75, 42.00]

print("Prices with 10% discount:")
for i in range(len(prices)):
    discounted = prices[i] * 0.9
    print(f"  Item {i+1}: €{discounted:.2f}")
```
