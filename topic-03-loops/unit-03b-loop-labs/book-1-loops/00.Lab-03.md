# Lab 03 — Loops

## Objectives

By the end of this lab you will be able to:

- Use a **while loop** to repeat code while a condition is true
- Use a **for loop** to iterate over sequences and ranges
- Use **range()** with start, stop, and step values
- Apply **break** and **continue** to control loop execution
- Write **nested loops** to solve two-dimensional problems
- Apply **accumulation patterns** to compute totals, counts, and products

## Prerequisites

- You have completed Lab 02 (Conditional Control)
- VS Code is open with a Python file ready to run

## Setup

Create a new folder called `lab03` in your course workspace and open it in VS Code.

Create a new file called `loops.py` for your work in this lab.
