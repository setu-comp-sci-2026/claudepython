# For Loops

A `for` loop iterates over every item in a sequence — a list, string, range, or any iterable.

## Step 1 — Looping Over a List

```python
fruits = ["apple", "banana", "cherry", "date"]

for fruit in fruits:
    print(fruit)
```

**Try it:** add more fruits to the list. The loop adapts automatically.

## Step 2 — Sum of a List

```python
scores = [85, 92, 78, 95, 61, 88]

total = 0
for score in scores:
    total += score

average = total / len(scores)
print(f"Total:   {total}")
print(f"Average: {average:.1f}")
```

## Step 3 — Multiplication Table

```python
number = int(input("Enter a number for its times table: "))

print(f"\nMultiplication table for {number}:")
for i in range(1, 13):
    print(f"  {number} × {i:2} = {number * i:3}")
```

The `:2` and `:3` in the f-string format integers to a minimum width, giving a neat column layout.

## Step 4 — Looping Over a String

```python
word = input("Enter a word: ")
vowel_count = 0

for char in word.lower():
    if char in "aeiou":
        vowel_count += 1

print(f"'{word}' contains {vowel_count} vowel(s)")
```
