# Lab 12 — Abstraction and Sorting

## Objectives

By the end of this lab you will be able to:

- Create an abstract class using `ABC` and `@abstractmethod`
- Implement concrete subclasses that satisfy the abstract contract
- Implement Bubble Sort and Selection Sort from scratch
- Implement Linear Search and Binary Search
- Use Python's built-in `sort()` with a `key=` function
- Use the `bisect` module for efficient searching
