# Step 2 — Implementing Bubble Sort

## 2.1 — Basic implementation

Create `sorting.py`:

```python
def bubble_sort(lst: list) -> list:
    data = lst.copy()
    n = len(data)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if data[j] > data[j + 1]:
                data[j], data[j + 1] = data[j + 1], data[j]
    return data

numbers = [64, 25, 12, 22, 11]
print(bubble_sort(numbers))
# Expected: [11, 12, 22, 25, 64]
```

## 2.2 — With early termination

```python
def bubble_sort_optimised(lst: list) -> list:
    data = lst.copy()
    n = len(data)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if data[j] > data[j + 1]:
                data[j], data[j + 1] = data[j + 1], data[j]
                swapped = True
        if not swapped:
            break   # list is already sorted!
    return data
```
