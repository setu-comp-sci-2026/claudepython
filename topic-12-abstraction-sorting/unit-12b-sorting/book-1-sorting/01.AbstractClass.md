# Step 1 — Implementing an Abstract Shape Class

## 1.1 — Define the abstract base class

Create `shape.py`:

```python
from abc import ABC, abstractmethod
import math

class Shape(ABC):

    @abstractmethod
    def area(self) -> float:
        """Return the area of this shape."""
        pass

    @abstractmethod
    def perimeter(self) -> float:
        """Return the perimeter of this shape."""
        pass

    def describe(self) -> str:
        return (f"{type(self).__name__}: "
                f"area={self.area():.2f}, "
                f"perimeter={self.perimeter():.2f}")

    def is_larger_than(self, other: "Shape") -> bool:
        return self.area() > other.area()
```

## 1.2 — Implement Circle

```python
class Circle(Shape):
    def __init__(self, radius: float):
        if radius <= 0:
            raise ValueError("Radius must be > 0")
        self.__r = radius

    def area(self) -> float:
        return math.pi * self.__r ** 2

    def perimeter(self) -> float:
        return 2 * math.pi * self.__r
```

## 1.3 — Implement Rectangle

```python
class Rectangle(Shape):
    def __init__(self, width: float, height: float):
        self.__w = width
        self.__h = height

    def area(self) -> float:
        return self.__w * self.__h

    def perimeter(self) -> float:
        return 2 * (self.__w + self.__h)
```

## 1.4 — Test it

```python
shapes = [Circle(5), Rectangle(4, 6), Circle(3)]

for s in shapes:
    print(s.describe())

# Can't instantiate Shape directly:
try:
    s = Shape()
except TypeError as e:
    print(f"Error: {e}")
```
