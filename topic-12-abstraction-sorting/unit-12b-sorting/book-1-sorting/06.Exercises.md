# Exercises

## Exercise 1 — Triangle Shape

Add a `Triangle(Shape)` class with base and height. Implement `area()` (= 0.5 * base * height) and `perimeter()` (requires all three sides — use `a`, `b`, `c` as constructor args, validate the triangle inequality).

## Exercise 2 — Sort Strings by Length

Write a function that sorts a list of strings by length using both `bubble_sort` and `sorted()` with `key=len`. Compare the outputs.

## Exercise 3 — Binary Search Count

Modify `binary_search` to also count and return the number of comparisons made. Compare with `linear_search` comparison count for large lists.

## Exercise 4 — Sort Products, Then Binary Search

1. Sort a list of Product objects by price (using `sorted()`)
2. Extract prices into a separate list
3. Use `binary_search` to find the index of a specific price
4. Retrieve and print the full Product at that index
