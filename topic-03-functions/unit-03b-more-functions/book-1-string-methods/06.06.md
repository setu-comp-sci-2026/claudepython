# f-Strings and Formatting Specifiers

## f-String Basics

f-strings embed any Python expression directly inside a string by prefixing it with `f` and placing the expression in `{}`.

Create a new Python file and try the following:

~~~python
name  = "Alice"
age   = 25
score = 87.654

print(f"Name: {name}, Age: {age}")     # Name: Alice, Age: 25
print(f"Next year I'll be {age + 1}")  # Next year I'll be 26
print(f"Score: {score:.2f}")           # Score: 87.65
~~~

## Number Formatting

Place a format specifier after a colon inside `{}`:

~~~python
price = 1234567.89
ratio = 0.756

print(f"€{price:,.2f}")        # €1,234,567.89  — thousands separator + 2dp
print(f"{ratio:.1%}")          # 75.6%           — percentage
print(f"{42:05d}")             # 00042           — zero-padded integer
~~~

## Alignment

Use `<`, `>`, or `^` with a width to align text in a fixed-width field:

~~~python
print(f"{'Left':<10}|")        # Left       |
print(f"{'Right':>10}|")       #      Right |
print(f"{'Centre':^10}|")      #   Centre   |
~~~

This is very useful for printing formatted tables:

~~~python
print(f"{'Item':<12} {'Price':>8}")
print("-" * 21)
print(f"{'Milk':<12} €{1.29:>7.2f}")
print(f"{'Bread':<12} €{2.49:>7.2f}")
print(f"{'Eggs':<12} €{3.99:>7.2f}")
~~~

Output:

~~~
Item              Price
---------------------
Milk             €1.29
Bread            €2.49
Eggs             €3.99
~~~

Run the code and confirm the columns are aligned.
