# Challenges

For each challenge, create a new Python file in VS Code.  All functions must include a docstring.


## Challenge 1

Write a function `validate_email(email)` that cleans and validates an email address.  It should:

1. Strip whitespace and convert to lowercase
2. Return `(None, "Missing @ symbol")` if `@` is not present
3. Return `(None, "Missing domain")` if there is no `.` after the `@`
4. Return `(None, "Username too short")` if the part before `@` is fewer than 2 characters
5. Return `(cleaned_email, "Valid")` if all checks pass

Test with individual calls:

~~~python
print(validate_email("  Alice@Example.COM  "))
print(validate_email("notanemail"))
print(validate_email("missing@dot"))
print(validate_email("a@b.com"))
print(validate_email("  VALID.USER@domain.ie  "))
~~~

Hint: use `partition("@")` to split on the `@` in one step.


## Challenge 2

Write a URL parser module with these pure functions:

- `get_scheme(url)` — returns the scheme, e.g. `"https"` — everything before `"://"`
- `get_domain(url)` — returns the domain, e.g. `"www.example.com"` — the part after `"://"` up to the next `"/"`
- `get_path(url)` — returns the path, e.g. `"/search/results"` — everything after the domain, up to `"?"` (or the end if there is no query string)
- `get_query(url)` — returns the query string, e.g. `"q=python&page=2"` — everything after `"?"`, or `""` if none

All four functions can be written using `split()`, `partition()`, and slicing — no loops needed.

Test with:

~~~python
url = "https://www.example.com/search/results?q=python&page=2"
print(get_scheme(url))   # https
print(get_domain(url))   # www.example.com
print(get_path(url))     # /search/results
print(get_query(url))    # q=python&page=2

url2 = "http://docs.python.org/3/library/string.html"
print(get_scheme(url2))  # http
print(get_domain(url2))  # docs.python.org
print(get_path(url2))    # /3/library/string.html
print(get_query(url2))   # (empty string)
~~~


## Challenge 3

Write a `caesar_cipher(text, shift)` function that encrypts a string using the Caesar cipher — each letter is shifted `shift` positions in the alphabet, wrapping around.  Non-letter characters are left unchanged.

Use `str.maketrans()` and `str.translate()` — no character-by-character loop needed.

Hint: `"abcdefghijklmnopqrstuvwxyz"[shift:]` gives the letters from position `shift` onwards; concatenate with `[: shift]` to build the rotated alphabet.  Pass the original and rotated alphabets to `str.maketrans()`, then call `.translate()` on the text.

~~~python
message   = "Hello, World!"
encrypted = caesar_cipher(message, 13)
print(encrypted)                  # Uryyb, Jbeyq!

decrypted = caesar_cipher(encrypted, 13)
print(decrypted)                  # Hello, World!
~~~

> **Note:** For ROT-13, applying the cipher twice returns the original because `13 + 13 = 26`.  Try other shift values too.
