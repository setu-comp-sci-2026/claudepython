For each exercise, create a new Python file in VS Code.  All functions must include a docstring.


## Exercise 1 (case and strip)

Write a function `normalise(text)` that:
1. Strips leading and trailing whitespace
2. Converts to title case
3. Replaces any double spaces with a single space

Test it with these inputs and confirm the output matches:

~~~python
print(normalise("  alice   smith  "))   # Alice Smith
print(normalise("JOHN  DOE"))           # John Doe
print(normalise("  mary   "))           # Mary
~~~


## Exercise 2 (search and replace)

Write a function `clean_phone(number)` that takes a phone number string and returns it with all spaces, dashes, and brackets removed, keeping only digits and a leading `+` if present.

~~~python
print(clean_phone("(01) 234-5678"))    # 0123456789
print(clean_phone("+353 86 123 4567")) # +353861234567
print(clean_phone("086-555-1234"))     # 0865551234
~~~

Hint: use `replace()` for each unwanted character in turn.

## Exercise 4 (f-string formatting)

First, write a helper function `format_item(name, qty, unit_price)` that returns a single formatted receipt line.  The item name should be left-aligned in 15 characters; the quantity right-aligned in 2; the line total right-aligned with 2 decimal places.

~~~python
print(format_item("Coffee", 2, 3.50))   # Coffee          2   €  7.00
print(format_item("Cake",   1, 4.75))   # Cake            1   €  4.75
print(format_item("Tea",    3, 2.00))   # Tea             3   €  6.00
~~~

Then write `print_receipt(title, name1, qty1, price1, name2, qty2, price2, name3, qty3, price3)` that prints a three-item receipt with a centred title, separator lines, and a total.

~~~python
print_receipt("CAFÉ RECEIPT",
              "Coffee", 2, 3.50,
              "Cake",   1, 4.75,
              "Tea",    3, 2.00)
~~~

Expected output:

~~~
