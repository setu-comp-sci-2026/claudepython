# Split and Join

## split()

`split()` breaks a string into a list of parts.  Called with no argument it splits on any whitespace; pass a delimiter to split on a specific character.

Create a new Python file and try the following:

~~~python
# Split on whitespace (default)
sentence = "the quick brown fox"
words = sentence.split()
print(words)        # ['the', 'quick', 'brown', 'fox']
print(len(words))   # 4

# Split on a specific delimiter
csv_line = "Alice,25,Dublin,Engineer"
parts = csv_line.split(",")
print(parts)        # ['Alice', '25', 'Dublin', 'Engineer']

name, age, city, job = parts    # unpack directly
print(f"{name} works as a {job} in {city}")
~~~

## join()

`join()` is the reverse of `split()` — it glues a list of strings together with a separator:

~~~python
words = ["Python", "is", "great"]

print(" ".join(words))      # Python is great
print("-".join(words))      # Python-is-great
print("".join(words))       # Pythonisgreat
print(", ".join(words))     # Python, is, great
~~~

The pattern is `"separator".join(list)` — the separator goes on the *left*.

## split() and join() Together

A common pattern is to split a string, access the parts by index, and rejoin with a different separator:

~~~python
# Split a full name and reformat it
full_name = "alice mary smith"
parts     = full_name.split()          # ['alice', 'mary', 'smith']

first = parts[0].title()               # 'Alice'
last  = parts[-1].title()              # 'Smith'
print(f"{last}, {first}")              # Smith, Alice

# Rejoin with a different separator
csv_line = "Dublin,Cork,Galway,Limerick"
cities   = csv_line.split(",")
print(" | ".join(cities))              # Dublin | Cork | Galway | Limerick
print(cities[0])                       # Dublin  (access by index)
print(cities[-1])                      # Limerick
~~~
