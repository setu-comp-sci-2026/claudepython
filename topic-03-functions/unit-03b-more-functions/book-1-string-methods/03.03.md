# Case and Whitespace Methods

## Case Methods

Create a new Python file and try the case methods:

~~~python
text = "Hello, World!"

print(text.upper())         # HELLO, WORLD!
print(text.lower())         # hello, world!
print(text.title())         # Hello, World!
print(text.capitalize())    # Hello, world!
print(text.swapcase())      # hELLO, wORLD!
~~~

Run the code and confirm each output.  Notice `swapcase()` flips every letter.

## Whitespace Methods

`strip()` removes leading and trailing whitespace (spaces, tabs, newlines):

~~~python
text = "  Hello, World!  "

print(text.strip())     # "Hello, World!"      both ends
print(text.lstrip())    # "Hello, World!  "    left only
print(text.rstrip())    # "  Hello, World!"    right only
~~~

This is very useful for cleaning up user input:

~~~python
name = input("Enter your name: ")
clean_name = name.strip().title()
print(f"Hello, {clean_name}!")
~~~

## Checking Methods

These methods return `True` or `False`:

~~~python
print("PYTHON".isupper())       # True
print("python".islower())       # True
print("Python123".isalnum())    # True  (letters and digits only)
print("   ".isspace())          # True
print("123".isdigit())          # True
print("hello".isalpha())        # True  (letters only)
~~~

Try each with values that should return `False` and confirm the result.
