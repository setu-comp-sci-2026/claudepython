# Strings are Objects

In Python, everything is an object — including strings.  Objects have *methods* (functions attached to them) that you call using dot notation: `object.method()`.

Create a new Python file and try the following:

~~~python
name = "hello world"
print(type(name))           # <class 'str'>

print(name.upper())         # HELLO WORLD
print(name.capitalize())    # Hello world
print(name.title())         # Hello World
~~~

Run the code.  Notice the difference between `capitalize()` (only the very first letter) and `title()` (first letter of every word).

## Strings are Immutable

Calling a method on a string does *not* change the original — it always returns a *new* string:

~~~python
greeting = "hello"
upper_greeting = greeting.upper()

print(greeting)         # hello  — unchanged
print(upper_greeting)   # HELLO  — new string
~~~

You must assign the result to a variable if you want to keep it.

## Chaining Methods

Because each method returns a new string, you can chain calls together:

~~~python
raw = "  alice smith  "
clean = raw.strip().title()
print(clean)    # Alice Smith
~~~

Python evaluates left to right: `strip()` removes the spaces first, then `title()` capitalises each word.
