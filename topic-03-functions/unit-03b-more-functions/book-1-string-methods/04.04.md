# Search and Replace

## Finding Substrings

Create a new Python file and try the search methods:

~~~python
sentence = "The quick brown fox jumps over the lazy dog"

print(sentence.find("fox"))         # 16  — index of first match
print(sentence.find("cat"))         # -1  — not found
print(sentence.count("the"))        # 1   — case-sensitive
print(sentence.count("e"))          # 3   — counts all occurrences

print(sentence.startswith("The"))   # True
print(sentence.endswith("dog"))     # True
print(sentence.startswith("the"))   # False  — case-sensitive
~~~

Note that `find()` returns `-1` when the substring is not found — not an error.

## The `in` Operator

You can also check membership using `in`, which is often cleaner than `find()` when you only need to know if something is present:

~~~python
if "fox" in sentence:
    print("Found a fox!")

if "@" not in "hello_world":
    print("Not an email address")
~~~

## Replacing

`replace()` returns a new string with all occurrences swapped:

~~~python
sentence = "The quick brown fox jumps over the lazy dog"

new_sentence = sentence.replace("fox", "cat")
print(new_sentence)
# The quick brown cat jumps over the lazy dog

# Replace only the first N occurrences
text = "aaa bbb aaa ccc aaa"
print(text.replace("aaa", "YYY", 2))
# YYY bbb YYY ccc aaa   — third occurrence left unchanged
~~~

Remember: the original string is unchanged.  `replace()` always returns a new string.
