## Exercise 4 — Number Formatter

Write a function `format_number(n)` that formats a number as:
- If 0 <= n < 1: show as percentage `"85.23%"`
- If integer: `"1,234"`
- If decimal: `"1,234.56"` (2 decimal places)

```python
print(format_number(1234567))   # 1,234,567
print(format_number(9876.543))  # 9,876.54
print(format_number(0.7523))    # 75.23%
```
