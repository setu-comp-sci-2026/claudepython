# The return Statement and Multiple Return Values

## The return Statement

`return` does two things at once: it sends a value back to the caller *and* immediately exits the function.  Nothing after a `return` in the same branch will ever run.

Create a new Python file and try the following:

~~~python
def square(n):
    return n * n

result = square(7)
print(result)               # 49
print(square(5) + 1)        # 26
print(square(square(3)))    # 81
~~~

Notice how the return value can be stored in a variable, used directly in an expression, or even passed as an argument to another call.

## Multiple Return Statements

A function can contain more than one `return` — the first one reached ends the function immediately:

~~~python
def absolute_value(n):
    if n < 0:
        return -n    # exits here for negative numbers
    return n         # exits here for zero or positive

print(absolute_value(-5))   # 5
print(absolute_value(0))    # 0
print(absolute_value(7))    # 7
~~~

Run the code and confirm the output.  Add a `print("still running")` line *after* each `return` inside the function and confirm it is never reached.

## Returning Multiple Values

Python allows a function to return more than one value.  The values are packed into a *tuple* automatically:

~~~python
def min_max(numbers):
    """Return the minimum and maximum of a list."""
    return min(numbers), max(numbers)

lo, hi = min_max([3, 1, 7, 4, 2, 8, 5])
print(f"Min: {lo}, Max: {hi}")      # Min: 1, Max: 8
~~~

The left-hand side *unpacks* the tuple into separate variables.  You can also capture the whole tuple:

~~~python
def divide_with_remainder(a, b):
    quotient  = a // b
    remainder = a % b
    return quotient, remainder

q, r = divide_with_remainder(17, 5)
print(f"17 ÷ 5 = {q} remainder {r}")   # 17 ÷ 5 = 3 remainder 2

result = divide_with_remainder(100, 7)
print(result)                           # (14, 2)  — the raw tuple
~~~
