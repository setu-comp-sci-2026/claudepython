# Positional and Keyword Arguments

*Parameters* are the variable names listed in the `def` line. *Arguments* are the values passed when you call the function.

## Positional Arguments

With positional arguments, order matters — the first argument is assigned to the first parameter, the second to the second, and so on.

Create a new Python file and enter the following:

~~~python
def greet(name, time_of_day):
    print(f"Good {time_of_day}, {name}!")

greet("Alice", "morning")
greet("Bob", "evening")
~~~

Run it and confirm the output.  Now swap the arguments and observe what happens:

~~~python
greet("morning", "Alice")   # the values land in the wrong parameters
~~~

This shows why order matters with positional arguments.

## Positional Arguments and Order

Try this second example and predict the output *before* running it:

~~~python
def power(base, exponent):
    return base ** exponent

print(power(2, 8))    # 2 to the power of 8
print(power(8, 2))    # 8 to the power of 2
~~~

The two calls produce different results even though the same numbers are used — because their order is swapped.


## Keyword Arguments

*Keyword* arguments are passed by name, so order no longer matters:

~~~python
def create_user(username, email, age):
    print(f"User: {username}, Email: {email}, Age: {age}")

# All three as keyword arguments — any order works
create_user(email="alice@example.com", age=25, username="alice99")
~~~

You can also mix positional and keyword arguments — positional must come first:

~~~python
create_user("alice99", age=25, email="alice@example.com")   # OK
~~~

Try putting a keyword argument before a positional one and observe the `SyntaxError`:

~~~python
create_user(username="alice99", "alice@example.com", 25)    # SyntaxError
~~~
