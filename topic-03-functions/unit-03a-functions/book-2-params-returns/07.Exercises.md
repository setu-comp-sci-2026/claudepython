# Exercises

For each exercise, create a new Python file in VS Code.  All functions must include a docstring.


## Exercise 1 (positional and keyword arguments)

Write a function `describe_person(name, age, city="Unknown", job="Unknown")` that prints a one-line description.

Call it in four different ways:
1. All positional arguments
2. All keyword arguments (in a different order)
3. Only the required arguments (let defaults apply)
4. Required arguments plus one keyword override

Example output for call 1:
~~~
Alice (28) works as a Developer and lives in Dublin.
~~~


## Exercise 2 (return values)

Write a function `circle_stats(radius)` that returns *both* the area and circumference of a circle as a tuple.  Use `import math` and `math.pi`.

Then unpack the result and print both values formatted to 2 decimal places:

~~~
Radius: 5
Area:         78.54
Circumference: 31.42
~~~

Test with at least three different radius values.


## Exercise 3 (ternary expression)

Write each of the following as a single-line function using the ternary expression:

- `is_positive(n)` — returns `"positive"` or `"non-positive"`
- `larger(a, b)` — returns whichever of `a` or `b` is greater
- `clamp(value, low, high)` — returns `low` if `value < low`, `high` if `value > high`, otherwise `value`

> **Note:** `clamp` needs two conditions — you can nest ternaries: `a if x else (b if y else c)`, but only do this when it still reads clearly.

Test each function with values that hit both branches.


## Exercise 4 (chained early returns)

Write a function `shipping_cost(weight_kg)` that returns the shipping cost based on weight:

| Weight          | Cost    |
|-----------------|---------|
| Up to 1 kg      | €3.00   |
| 1 kg – 5 kg     | €5.50   |
| 5 kg – 20 kg    | €9.00   |
| Over 20 kg      | €15.00  |

Use chained early returns (no `elif`).

Then write a `print_quote(weight_kg)` function that calls `shipping_cost` and prints a formatted quote.  Test with weights of 0.5, 2, 10, and 25 kg.
