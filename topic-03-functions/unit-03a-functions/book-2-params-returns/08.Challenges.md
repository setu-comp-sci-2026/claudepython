# Challenges

For each challenge, create a new Python file in VS Code.  All functions must include a docstring.


## Challenge 1

Build a simple invoice calculator.  Write the following functions:

- `line_total(qty, unit_price, discount=0.0)` — returns `qty * unit_price * (1 - discount)`
- `apply_vat(amount, rate=0.23)` — returns `amount * (1 + rate)`
- `format_money(amount)` — returns a string formatted as `€12.50`
- `print_invoice(items)` — takes a list of `(name, qty, price)` tuples, prints a formatted invoice with line totals, subtotal, VAT, and grand total

Example output:
~~~
==============================
           INVOICE
==============================
Coffee         3 x €3.50  = €10.50
Sandwich       2 x €5.00  = €10.00
Water          4 x €1.20  = €4.80
------------------------------
Subtotal:               €25.30
VAT (23%):               €5.82
==============================
Total:                  €31.12
==============================
~~~


## Challenge 2

Write a mini statistics library with the following functions, each returning a single value:

- `mean(numbers)` — arithmetic average
- `median(numbers)` — middle value when sorted (average of two middles for even-length lists)
- `mode(numbers)` — most frequently occurring value
- `std_dev(numbers)` — population standard deviation: `sqrt(mean of squared differences from mean)`

Then write a `full_report(numbers)` function that calls all four and prints the results formatted to 2 decimal places.

Test with: `[4, 7, 2, 9, 4, 1, 7, 4, 8, 3]`


## Challenge 3

Redesign the following poorly structured program by splitting it into well-named single-responsibility functions.  Each function must have a docstring, accept its data as parameters, and return its result rather than printing it — except for any function whose sole purpose is to display output.

~~~python
# Original — do not modify this; rewrite it below
def run():
    scores = []
    while True:
        raw = input("Enter score (or 'done'): ")
        if raw.lower() == "done":
            break
        score = float(raw)
        if score < 0 or score > 100:
            print("Invalid score — must be 0-100")
            continue
        scores.append(score)
    if not scores:
        print("No scores entered.")
        return
    total   = sum(scores)
    average = total / len(scores)
    highest = max(scores)
    lowest  = min(scores)
    grade   = "A" if average >= 90 else "B" if average >= 80 else "C" if average >= 70 else "D" if average >= 60 else "F"
    print(f"Count:   {len(scores)}")
    print(f"Average: {average:.1f}  Grade: {grade}")
    print(f"Highest: {highest}  Lowest: {lowest}")

run()
~~~

Your refactored version should have at least five separate functions.
