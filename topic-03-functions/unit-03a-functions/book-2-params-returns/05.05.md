# Conditional Returns

## Ternary Expression

A *ternary expression* lets you return one of two values on a single line, avoiding a full `if/else` block.  The syntax is:

~~~
return <value_if_true> if <condition> else <value_if_false>
~~~

Create a new Python file and try these examples:

~~~python
def is_even(n):
    return "even" if n % 2 == 0 else "odd"

def passes(score):
    return "Pass" if score >= 60 else "Fail"

def absolute_value(n):
    return n if n >= 0 else -n

print(is_even(4))           # even
print(is_even(7))           # odd
print(passes(75))           # Pass
print(passes(45))           # Fail
print(absolute_value(-9))   # 9
~~~

Run the code and confirm each result.

The ternary is best when there are exactly *two* outcomes and both fit clearly on one line.  For three or more branches, use chained returns instead.

## Chained Early Returns

When a function has several possible outcomes, you can use a chain of `if` statements, each returning immediately.  The first condition that matches exits the function — so no `elif` is needed:

~~~python
def calculate_grade(score):
    """Return a letter grade for a numeric score."""
    if score >= 90: return "A"
    if score >= 80: return "B"
    if score >= 70: return "C"
    if score >= 60: return "D"
    return "F"

print(calculate_grade(95))   # A
print(calculate_grade(83))   # B
print(calculate_grade(73))   # C
print(calculate_grade(61))   # D
print(calculate_grade(42))   # F
~~~

Run the code.  Then try converting it to use `elif` and compare the two versions — both are correct, but the chained version is easier to scan because each branch is on one line.

## Combining Both Patterns

~~~python
def describe_temperature(celsius):
    """Return a description of a temperature in Celsius."""
    if celsius < 0:   return "freezing"
    if celsius < 10:  return "cold"
    if celsius < 20:  return "cool"
    if celsius < 30:  return "warm"
    return "hot"

def format_temp(celsius):
    """Return a formatted temperature string with description."""
    desc = describe_temperature(celsius)
    symbol = "°C"
    return f"{celsius}{symbol} — {desc}"

for temp in [-5, 5, 15, 25, 35]:
    print(format_temp(temp))
~~~
