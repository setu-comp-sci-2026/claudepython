# Challenges

For each challenge, create a new Python file in VS Code.  All functions must include a docstring.


## Challenge 1

A common beginner mistake is to mix I/O, logic, and state all together.  The program below works but is poorly structured:

~~~python
score_total = 0
score_count = 0

def add_score():
    global score_total, score_count
    raw = input("Enter score: ")
    score = float(raw)
    score_total += score
    score_count += 1
    print(f"Running average: {score_total / score_count:.1f}")

for _ in range(3):
    add_score()
~~~

Rewrite it so that:
- There are no global variables
- All logic (averaging) is in pure functions
- All I/O (`input`, `print`) is in clearly separated impure functions
- The main program reads clearly top to bottom

Your output should be identical to the original.


## Challenge 2

Write a `mortgage.py` module that uses constants and intermediate variables to calculate mortgage information.

Define these constants:

~~~python
MONTHS_PER_YEAR = 12
STAMP_DUTY_RATE = 0.01     # 1% on properties under €1M
~~~

Write the following pure functions with intermediate variables:

- `monthly_rate(annual_rate)` — returns `annual_rate / MONTHS_PER_YEAR`
- `n_payments(years)` — returns `years * MONTHS_PER_YEAR`
- `monthly_payment(principal, annual_rate, years)` — uses the above two functions as intermediate steps; formula: `P * r * (1+r)^n / ((1+r)^n - 1)` where `r = monthly_rate` and `n = n_payments`
- `stamp_duty(price)` — returns `price * STAMP_DUTY_RATE`
- `total_cost(principal, annual_rate, years)` — returns total amount repaid over the full term

Then write an impure `print_mortgage_summary(price, deposit, annual_rate, years)` that calls all the above and prints a formatted summary.

Example output:
~~~
==============================
      MORTGAGE SUMMARY
==============================
Property price:    €350,000
Deposit:            €35,000
Loan amount:       €315,000
Annual rate:          4.00%
Term:               30 years
------------------------------
Monthly payment:    €1,504.43
Total repaid:     €541,595.40
Stamp duty:         €3,500.00
==============================
~~~


## Challenge 3

Write a `unit_converter.py` module that demonstrates good use of constants, pure functions, and intermediate variables.

Define constants for common conversion factors:

~~~python
KG_PER_LB    = 0.453592
M_PER_FOOT   = 0.3048
KM_PER_MILE  = 1.60934
C_OFFSET      = 32
C_SCALE       = 5 / 9
~~~

Write pure conversion functions (each with intermediate variables where it aids clarity) for:
- `lbs_to_kg(lbs)` and `kg_to_lbs(kg)`
- `feet_to_metres(feet)` and `metres_to_feet(m)`
- `miles_to_km(miles)` and `km_to_miles(km)`
- `fahrenheit_to_celsius(f)` and `celsius_to_fahrenheit(c)`

Then write an impure `conversion_table(values, from_unit)` function that takes a list of values and a unit string (`"lbs"`, `"feet"`, `"miles"`, or `"fahrenheit"`) and prints a tidy two-column conversion table.

Example output for `conversion_table([100, 150, 200], "lbs")`:
~~~
lbs          kg
-----------  -----------
100          45.36
150          68.04
200          90.72
~~~
