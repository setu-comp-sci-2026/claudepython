# Local and Global Scope

Every variable in Python lives in a *scope* — the region of code where it can be accessed.  There are two main scopes to understand first: *global* and *local*.

- A **global** variable is defined at the top level of a file, outside any function.
- A **local** variable is defined inside a function and only exists while that function is running.

Create a new Python file and enter the following:

~~~python
message = "I am global"    # global scope

def show_message():
    local_msg = "I am local"   # local scope
    print(message)             # functions can read globals
    print(local_msg)

show_message()
print(message)      # OK — message is global
print(local_msg)    # NameError — local_msg doesn't exist here
~~~

Run the code.  You will see a `NameError` on the last line because `local_msg` was created inside `show_message()` and is destroyed when the function returns.

Remove the last `print(local_msg)` line so the rest runs cleanly.

## Each Call Gets Its Own Locals

Local variables are created fresh on every function call and discarded when it returns:

~~~python
def count_up(start):
    step = 1               # local to this call
    print(start + step)

count_up(10)    # step = 1, prints 11
count_up(20)    # a brand-new step = 1, prints 21

# step does not exist here
~~~

## Reading a Global from Inside a Function

A function can *read* a global variable without any special syntax:

~~~python
greeting = "Hello"

def greet(name):
    print(f"{greeting}, {name}!")    # reads global fine

greet("Alice")
greet("Bob")
~~~

Run this and confirm it works.  You will see in the next step why *modifying* a global from inside a function is a different matter.
