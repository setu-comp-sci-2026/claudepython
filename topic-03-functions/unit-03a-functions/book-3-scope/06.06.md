# Constants and Intermediate Variables

## Constants

A *constant* is a module-level name whose value never changes during a program run.  By convention, Python constants are written in **ALL_CAPS** with underscores.  This signals to anyone reading the code that the value is not meant to be modified.

Create a new Python file and try the following:

~~~python
PI       = 3.14159265
GRAVITY  = 9.81       # m/s²
TAX_RATE = 0.23
MAX_SCORE = 100

def circle_area(radius):
    """Return the area of a circle."""
    return PI * radius ** 2

def circle_circumference(radius):
    """Return the circumference of a circle."""
    return 2 * PI * radius

def apply_tax(price):
    """Return price with tax added."""
    return price * (1 + TAX_RATE)

print(f"Circle area (r=5):     {circle_area(5):.2f}")
print(f"Circumference (r=5):   {circle_circumference(5):.2f}")
print(f"Price with tax (€100): {apply_tax(100):.2f}")
~~~

Note that `PI` appears in two functions.  If you ever needed to use a more precise value of π, you only change it in one place.

## Intermediate Variables

An *intermediate variable* holds a computed result temporarily — it names a stepping stone between input and output, making the code easier to read and debug.

~~~python
def monthly_payment(principal, annual_rate, years):
    """Calculate monthly loan repayment."""
    monthly_rate = annual_rate / 12       # intermediate
    n_payments   = years * 12             # intermediate
    factor       = (1 + monthly_rate) ** n_payments   # intermediate
    return principal * monthly_rate * factor / (factor - 1)

payment = monthly_payment(200000, 0.04, 30)
print(f"Monthly payment: €{payment:.2f}")
~~~

Without intermediate variables this would be a single unreadable expression.  With them you can `print()` any step to inspect it during debugging.

## When Not to Use Them

Intermediate variables add value when an expression is complex or reused.  A one-line wrapper around something obvious just adds noise:

~~~python
# Unnecessary
def square(n):
    result = n * n
    return result

# Better
def square(n):
    return n * n
~~~

## Putting It Together

~~~python
def calculate_statistics(numbers):
    """Return mean, minimum, and maximum for a list of numbers."""
    if not numbers:
        return None, None, None
    count   = len(numbers)      # intermediate
    total   = sum(numbers)      # intermediate
    mean    = total / count     # intermediate — reuses total and count
    minimum = min(numbers)      # intermediate
    maximum = max(numbers)      # intermediate
    return mean, minimum, maximum

data = [23, 45, 12, 67, 34, 89, 56]
avg, lo, hi = calculate_statistics(data)
print(f"Mean:  {avg:.1f}")
print(f"Range: {lo} to {hi}")
~~~

All five intermediate variables are local — they are discarded as soon as the function returns.
