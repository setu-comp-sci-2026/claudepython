# Pure and Impure Functions

A *pure function* has two properties:

1. **Same input always gives the same output** — no randomness, no reading from external state
2. **No side effects** — it doesn't modify anything outside itself, print to the screen, or read user input

Pure functions are easy to test, easy to reason about, and can be called any number of times safely.

## Pure Functions

Create a new Python file and try these examples:

~~~python
def multiply(a, b):
    """Return a multiplied by b."""
    return a * b

def clamp(value, minimum, maximum):
    """Constrain value to the range [minimum, maximum]."""
    return max(minimum, min(maximum, value))

def celsius_to_fahrenheit(c):
    """Convert Celsius to Fahrenheit."""
    return (c * 9 / 5) + 32

print(multiply(3, 4))                # always 12
print(clamp(150, 0, 100))           # always 100
print(celsius_to_fahrenheit(100))    # always 212.0
~~~

Call each function several times with the same arguments — you always get the same result.

## Impure Functions

*Impure* functions have side effects or depend on external state:

~~~python
def get_score():
    """Read a score from the user — impure (depends on input)."""
    return float(input("Score: "))

def log_result(msg):
    """Print a message — impure (side effect: printing)."""
    print(msg)

import random
def roll_die():
    """Return a random number — impure (different result each call)."""
    return random.randint(1, 6)
~~~

These are impure because their behaviour depends on something outside their parameters or they change something outside themselves.

## Separating Pure from Impure

The key practice is to keep the two separated — write your logic as pure functions and keep all I/O in clearly labelled impure functions:

~~~python
# Pure — the logic
def calculate_grade(score):
    """Return a letter grade. Pure: same input → same output."""
    if score >= 90: return "A"
    if score >= 80: return "B"
    if score >= 70: return "C"
    if score >= 60: return "D"
    return "F"

# Impure — the I/O
def get_score():
    """Prompt for a score. Impure: depends on user input."""
    return float(input("Enter score: "))

def show_grade(score, grade):
    """Display result. Impure: side effect (printing)."""
    print(f"Score {score:.1f} → Grade {grade}")

# Main program
score = get_score()
grade = calculate_grade(score)
show_grade(score, grade)
~~~

Write and run this program.  Notice that `calculate_grade` could be tested on its own with any score — it needs no input prompt and produces no output.
