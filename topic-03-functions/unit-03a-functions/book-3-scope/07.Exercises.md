# Exercises

For each exercise, create a new Python file in VS Code.  All functions must include a docstring.


## Exercise 1 (local vs global)

Run the following code *without changing it* first, and predict what each `print` will output before you run it:

~~~python
x = 10

def double():
    x = 20
    print(f"Inside double: {x}")

def triple():
    print(f"Inside triple: {x}")

double()
triple()
print(f"Global: {x}")
~~~

Write your predictions as comments at the top of the file, then run the code.  Were you correct?  Explain in a comment why `double()` does not change the global `x`.


## Exercise 2 (avoiding globals)

The following program uses a global variable to track a running total:

~~~python
running_total = 0

def add(value):
    global running_total
    running_total += value

add(15)
add(30)
add(5)
print(running_total)
~~~

Rewrite it without using `global`.  The rewritten version should produce the same output but use `return` to pass the updated total back to the caller.


## Exercise 3 (pure vs impure)

Classify each of the following functions as *pure* or *impure* and write a one-line reason as a comment.  Then write a corrected pure version of each impure function (where possible):

~~~python
import random

def add(a, b):
    return a + b

def get_name():
    return input("Name: ")

def to_uppercase(text):
    return text.upper()

def random_greeting():
    options = ["Hi", "Hello", "Hey"]
    return random.choice(options)

def print_total(total):
    print(f"Total: {total}")
~~~


## Exercise 4 (constants and intermediate variables)

Write a module called `physics.py` that defines the following constants at the top:

~~~python
GRAVITY   = 9.81     # m/s²
SPEED_OF_LIGHT = 299_792_458   # m/s
AIR_DENSITY = 1.225  # kg/m³
~~~

Then write these three pure functions, each using intermediate variables clearly named:

- `free_fall_velocity(time_s)` — returns velocity after falling for `time_s` seconds: `v = GRAVITY * t`
- `kinetic_energy(mass_kg, velocity_ms)` — returns `0.5 * m * v²`
- `drag_force(area_m2, velocity_ms, drag_coefficient=0.47)` — returns `0.5 * AIR_DENSITY * v² * area * Cd`

Print results for a few realistic values to verify your answers.
