# Challenges

For each challenge, create a new Python file in VS Code.  All functions must include a docstring.


## Challenge 1

Build a simple number-guessing game using functions.  Break the program into at least three functions:

- `get_secret_number()` — generates and returns a random integer between 1 and 100 (use `import random` and `random.randint(1, 100)`)
- `get_guess()` — prompts the user for a guess and returns it as an integer
- `check_guess(secret, guess)` — prints "Too high", "Too low", or "Correct!" and returns `True` if the guess is correct, `False` otherwise

The main program should keep asking for guesses until the user gets it right and should count how many attempts it took.

Example run:

~~~
Guess the number (1-100): 50
Too high
Guess the number (1-100): 25
Too low
Guess the number (1-100): 37
Correct! You got it in 3 attempts.
~~~


## Challenge 2

Write a program that generates a simple text report for a small class of students.  Use the following structure:

- `get_scores()` — asks the user how many students there are, then collects a name and score (0–100) for each, and returns two lists: `names` and `scores`
- `class_average(scores)` — returns the average score
- `highest_scorer(names, scores)` — returns the name of the student with the highest score
- `print_report(names, scores)` — prints a formatted table plus the class average and top student

Example output:

~~~
==============================
       CLASS REPORT
==============================
Alice        82.0   B
Bob          91.5   A
Carol        74.0   C
------------------------------
Average:     82.5
Top student: Bob
==============================
~~~


## Challenge 3

Write a module called `shapes.py` that contains the following functions, each with a proper docstring:

- `circle_area(radius)` — returns π × radius²
- `circle_circumference(radius)` — returns 2 × π × radius
- `rectangle_area(w, h)` — returns w × h
- `rectangle_perimeter(w, h)` — returns 2 × (w + h)
- `triangle_area(base, height)` — returns 0.5 × base × height

Use `import math` and `math.pi` for π.

Then create a separate file `test_shapes.py` that imports `shapes` and tests every function with at least two sets of inputs, printing the results clearly.  Verify your answers with a calculator.
