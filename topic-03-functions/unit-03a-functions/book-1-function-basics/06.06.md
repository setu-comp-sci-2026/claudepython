# Functions in Practice

Now that you understand the building blocks, we will build a small but complete program made entirely of functions.

## Step 1 — Utility Functions

Create a new Python file and start with two conversion functions:

~~~python
def celsius_to_fahrenheit(celsius):
    """Convert Celsius to Fahrenheit."""
    return (celsius * 9 / 5) + 32


def fahrenheit_to_celsius(fahrenheit):
    """Convert Fahrenheit to Celsius."""
    return (fahrenheit - 32) * 5 / 9


boiling_c = 100
boiling_f = celsius_to_fahrenheit(boiling_c)
print(f"{boiling_c}°C = {boiling_f}°F")

freezing_f = 32
freezing_c = fahrenheit_to_celsius(freezing_f)
print(f"{freezing_f}°F = {freezing_c}°C")
~~~

Run the code and confirm the output:

~~~
100°C = 212.0°F
32°F = 0.0°C
~~~

## Step 2 — Building a Student Grade Program

Now build a program where each task is handled by its own function.  Add the following to your file (or a new file):

~~~python
def get_student_data():
    """Prompt the user for a student name and score."""
    name  = input("Student name: ")
    score = float(input("Score (0-100): "))
    return name, score


def calculate_grade(score):
    """Return a letter grade for a numeric score."""
    if score >= 90: return "A"
    if score >= 80: return "B"
    if score >= 70: return "C"
    if score >= 60: return "D"
    return "F"


def print_result(name, score, grade):
    """Print a formatted student result."""
    print("-" * 30)
    print(f"Student: {name}")
    print(f"Score:   {score:.1f}")
    print(f"Grade:   {grade}")
    print("-" * 30)


# Main program
name, score = get_student_data()
grade       = calculate_grade(score)
print_result(name, score, grade)
~~~

Run the program, enter a name and score, and confirm the output looks correct.

Notice how the main program reads almost like plain English — each step delegates to a well-named function.  This is the key benefit of organising code into functions.
