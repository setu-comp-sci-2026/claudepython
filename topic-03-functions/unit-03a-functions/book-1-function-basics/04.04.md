# Void Functions and None

A function that has no `return` statement still returns a value — the special value `None`.  These are called *void* functions because they produce no meaningful result; their purpose is to *do something* (such as print output) rather than *calculate something*.

Create a new Python file and try the following:

~~~python
def greet(name):
    print(f"Hello, {name}!")

result = greet("Alice")
print(result)
print(type(result))
~~~

Run it.  You will see:

~~~
Hello, Alice!
None
<class 'NoneType'>
~~~

`None` represents "no value" in Python.  It is not zero and it is not an empty string — it is the *absence* of a value.

## A Common Mistake

A frequent error is to try to use the result of a void function in a calculation:

~~~python
def add(a, b):
    print(a + b)    # prints the result but does NOT return it

result = add(3, 4)      # prints 7
doubled = result * 2    # TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'
print(doubled)
~~~

Run this code and observe the `TypeError`.  The fix is to use `return` instead of `print` inside the function:

~~~python
def add(a, b):
    return a + b    # returns the result

result = add(3, 4)      # result is now 7, not None
doubled = result * 2    # works correctly
print(doubled)          # 14
~~~

## Checking for None

You can check whether a value is `None` using `is None`:

~~~python
def divide(a, b):
    if b == 0:
        return None
    return a / b

result = divide(10, 0)

if result is None:
    print("Cannot divide by zero")
else:
    print(f"Result: {result}")
~~~
