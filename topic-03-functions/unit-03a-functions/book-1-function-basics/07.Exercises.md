# Exercises

The exercises below are based on the material covered in this lab and the presentation slides.

For each exercise, create a new Python file in VS Code.  All functions must include a docstring.


## Exercise 1 (defining and calling)

Write three functions — `print_stars()`, `print_dashes()`, and `print_banner(title)` — where `print_banner()` calls the other two to produce output like this:

~~~
********************
   Python Rocks!
********************
~~~

The lines of stars should always be exactly 20 characters wide.  The title should be centred between them.

> **Note:** To repeat a character *n* times, use the `*` operator on a string — for example `"*" * 20` produces `"********************"`.  This was covered in the Data Types slides.

Hint: use `f"{title:^20}"` to centre a string in a field of width 20.


## Exercise 2 (return values)

Write a function `bmi(weight_kg, height_m)` that calculates and returns the Body Mass Index using the formula:

~~~
BMI = weight_kg / (height_m ** 2)
~~~

Then write a second function `bmi_category(bmi_value)` that returns the correct category string:

- Under 18.5 → `"Underweight"`
- 18.5–24.9 → `"Normal weight"`
- 25–29.9 → `"Overweight"`
- 30 or over → `"Obese"`

Write a small main program that asks the user for their weight (kg) and height (m), calculates the BMI, and prints the value and category formatted to 1 decimal place.


## Exercise 3 (void vs return)

Study the two functions below and, *before running the code*, predict what will be printed:

~~~python
def double_print(n):
    print(n * 2)

def double_return(n):
    return n * 2

a = double_print(5)
b = double_return(5)

print(a)
print(b)
print(type(a))
print(type(b))
~~~

Run the code and check your prediction.  Write a comment at the top of your file explaining the difference between the two functions.


## Exercise 4 (functions calling functions)

Write four small functions — `add(a, b)`, `subtract(a, b)`, `multiply(a, b)`, and `divide(a, b)` — and a fifth function `show_all(a, b)` that calls all four and prints the results neatly.  `divide` should return `None` and print a warning if `b` is zero.

Example output for `show_all(10, 4)`:

~~~
10 + 4  = 14
10 - 4  = 6
10 × 4  = 40
10 ÷ 4  = 2.5
~~~
