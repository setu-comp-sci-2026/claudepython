# What is a Function?

A *function* is a named, reusable block of code that performs a specific task.  You have already used built-in Python functions such as `print()`, `input()`, `int()`, and `float()`.  In this lab you will write your own.

Functions give you several important advantages:

- **Reuse** — write the code once and call it as many times as you need
- **Abstraction** — hide complexity behind a simple name
- **Organisation** — break a large program into small, manageable pieces
- **Testing** — test each piece independently
- **Maintenance** — fix a bug in one place and it is fixed everywhere

## Defining a Function

Functions are defined using the `def` keyword, followed by the function name, parentheses, and a colon.  The body of the function is indented.

```python
def function_name(parameters):
    """Optional docstring."""
    # function body
    return value   # optional
```

## Your First Function

In VS Code, create a new Python file and enter the following:

~~~python
def say_hello():
    print("Hello from my first function!")

say_hello()
say_hello()
say_hello()
~~~

Run the file.  You should see the message printed three times.  Notice that:

- The function is *defined* once using `def`
- It is *called* (invoked) three times by writing its name followed by `()`
- The function body is indented by four spaces

Try calling `say_hello()` a fourth time and confirm the output changes.
