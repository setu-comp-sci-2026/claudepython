# Docstrings

A *docstring* is a string literal placed at the very start of a function body.  It documents what the function does, what parameters it expects, and what it returns.  Docstrings are enclosed in triple quotes `"""`.

Create a new Python file called `calculate.py` and add the following:

~~~python
def calculate_area(width, height):
    """Calculate and return the area of a rectangle.

    Args:
        width:  The width of the rectangle (number).
        height: The height of the rectangle (number).

    Returns:
        The area as a number (width * height).
    """
    return width * height


def calculate_perimeter(width, height):
    """Calculate and return the perimeter of a rectangle.

    Args:
        width:  The width of the rectangle (number).
        height: The height of the rectangle (number).

    Returns:
        The perimeter as a number: 2 * (width + height).
    """
    return 2 * (width + height)


print(calculate_area(5, 3))
print(calculate_perimeter(5, 3))
~~~

Run the file to confirm it works.

## Accessing Docstrings

You can read a function's docstring in two ways.

**Using `help()`** — open a terminal, navigate to the folder containing `calculate.py`, and start the Python REPL:

~~~
$ python3
>>> import calculate
>>> help(calculate.calculate_area)
~~~

You will see the docstring displayed in a formatted help page.  Press `q` to exit.

**Using `.__doc__`** — from within the REPL (after importing):

~~~python
>>> print(calculate.calculate_area.__doc__)
Calculate and return the area of a rectangle.

Args:
    width:  The width of the rectangle (number).
    height: The height of the rectangle (number).

Returns:
    The area as a number (width * height).
~~~

## Best Practice

Every function you write should have a docstring.  Even a single-line docstring is better than none:

~~~python
def square(n):
    """Return n squared."""
    return n * n
~~~

This makes your code easier to understand for anyone who reads it later — including yourself.
