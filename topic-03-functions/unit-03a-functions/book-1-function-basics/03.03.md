# Calling Functions

A function does nothing until it is *called*.  You call a function by writing its name followed by `()`.

Create a new Python file and try the following:

~~~python
def greet():
    print("Good morning!")
    print("Welcome to Python.")

# Nothing has happened yet — we haven't called the function

greet()     # Now it runs
greet()     # Runs again
~~~

Run the code and confirm the two lines print twice.

## Functions Can Call Other Functions

Functions can call other functions.  This allows you to build up behaviour from smaller pieces:

~~~python
def draw_line():
    print("-" * 30)

def print_header(title):
    draw_line()
    print(title)
    draw_line()

print_header("Student Report")
print_header("Weekly Results")
~~~

Run this and observe the output.  Notice that `print_header()` calls `draw_line()` twice — you defined `draw_line()` once but it is reused inside `print_header()`.

## Order of Definition

Python reads files from top to bottom.  A function must be *defined* before it is *called*.

Try putting the call *before* the definition and observe the error:

~~~python
say_hello()     # NameError: name 'say_hello' is not defined

def say_hello():
    print("Hello!")
~~~

Then move the call to after the definition and confirm it works.
