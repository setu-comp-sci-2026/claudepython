# Basic Input and Output

## Step 1 — The input() Function

```python
# input() always returns a string
response = input("What is your favourite colour? ")
print(f"You chose: {response}")
print(f"Type: {type(response)}")
print(f"Length: {len(response)} characters")
```

## Step 2 — Multiple Inputs

```python
first_name = input("First name: ")
last_name  = input("Last name: ")
city       = input("City: ")

full_name = f"{first_name} {last_name}"
print(f"\nHello, {full_name} from {city}!")
print(f"Your name has {len(full_name)} characters")
```

## Step 3 — print() Options

```python
# Default: sep=" ", end="\n"
print("a", "b", "c")                # a b c

# Custom separator
print("a", "b", "c", sep="-")       # a-b-c
print("a", "b", "c", sep="")        # abc

# Custom end
print("Loading", end="")
for i in range(3):
    print(".", end="", flush=True)
print(" Done!")

# Print nothing (just a newline)
print()
```

## Step 4 — Input and Arithmetic

```python
# Demonstrate type conversion requirement
width_str  = input("Rectangle width: ")
height_str = input("Rectangle height: ")

width  = float(width_str)
height = float(height_str)

area      = width * height
perimeter = 2 * (width + height)

print(f"\nWidth:     {width}")
print(f"Height:    {height}")
print(f"Area:      {area}")
print(f"Perimeter: {perimeter}")
```
