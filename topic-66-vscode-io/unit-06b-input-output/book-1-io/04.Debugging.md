# Using the VS Code Debugger

## What You Will Do

In this section you will use VS Code's visual debugger to:
1. Set a breakpoint
2. Run the debugger
3. Inspect variable values
4. Step through code line by line

## Step 1 — Set Up the Buggy Program

Create a new file `debug_me.py` with this code (it has a logic bug):

```python
def calculate_average(scores):
    total = 0
    for score in scores:
        total = score       # BUG: should be +=
    average = total / len(scores)
    return average

scores = [85, 92, 78, 95, 61]
avg = calculate_average(scores)
print(f"Average: {avg:.1f}")    # Expected: 82.2
```

Run it — the result will be wrong (61.0 instead of 82.2).

## Step 2 — Set a Breakpoint

1. Click in the gutter to the left of line `total = score` (a red dot appears)
2. Press `F5` to start debugging (choose "Python File" if prompted)
3. The program will pause at your breakpoint

## Step 3 — Inspect Variables

With the program paused:
- Look at the **Variables** panel on the left — you can see `total` and `score`
- Press `F10` (**Step Over**) to execute the line and advance to the next one
- Watch how `total` changes — notice it gets *replaced* rather than *accumulated*

## Step 4 — Fix the Bug

Stop debugging (`Shift+F5`). Change `total = score` to `total += score`. Run again.

## Step 5 — Watch Expressions

1. Set a breakpoint inside the loop again
2. In the **Watch** panel, add the expression: `total / len(scores)`
3. Step through the loop — watch the running average update each iteration
