# Challenges

## Challenge 1 — Loan Repayment Calculator

Build an interactive loan calculator:

1. Ask for: loan amount, annual interest rate (%), loan term (years)
2. Validate all inputs (amount > 0, rate >= 0, term 1-30)
3. Calculate:
   - Monthly payment using the formula: `M = P * r(1+r)^n / ((1+r)^n - 1)` where P = principal, r = monthly rate, n = number of months
   - Total amount repaid
   - Total interest paid
4. Print a formatted summary
5. Print the first 12 months of an amortisation table showing: month number, payment, interest portion, principal portion, remaining balance

Example output:
```
=== Loan Repayment Summary ===
Principal:        €10,000.00
Annual rate:           5.00%
Term:                3 years
Monthly payment:    €299.71
Total repaid:    €10,789.56
Interest paid:      €789.56

Month  Payment  Interest  Principal  Balance
    1  €299.71    €41.67    €258.04 €9,741.96
    2  €299.71    €40.59    €259.12 €9,482.84
    ...
```

## Challenge 2 — Unit Converter

Build a multi-category unit converter:

Categories and units to support:
- **Length**: metres, kilometres, miles, feet, inches, centimetres
- **Weight**: kilograms, pounds, grams, ounces
- **Temperature**: Celsius, Fahrenheit, Kelvin

The program should:
1. Show a category menu
2. Show available units for that category
3. Ask for source unit, target unit, and value
4. Display the result with 4 decimal places
5. Loop back to let the user convert more values
6. Validate all inputs

Use dictionaries to store conversion factors to a base unit.
