# F-String Formatting Practice

## Step 1 — Basic f-Strings

```python
name  = "Alice"
score = 87.654
count = 1234567

# Basic embedding
print(f"Name: {name}")
print(f"Score: {score}")

# Expressions
print(f"Score doubled: {score * 2}")
print(f"Name length: {len(name)}")
print(f"Name uppercase: {name.upper()}")
```

## Step 2 — Number Formatting

```python
pi    = 3.14159265
price = 1234567.89
ratio = 0.8523

# Decimal places
print(f"Pi (2dp):  {pi:.2f}")
print(f"Pi (4dp):  {pi:.4f}")
print(f"Pi (0dp):  {pi:.0f}")

# Thousands separator
print(f"Price:     €{price:,.2f}")
print(f"Price:     €{price:,.0f}")

# Percentage
print(f"Pass rate: {ratio:.1%}")
print(f"Pass rate: {ratio:.2%}")

# Scientific notation
print(f"Pi sci:    {pi:.3e}")
```

## Step 3 — Alignment

```python
name = "Alice"

# Width and alignment
print(f"|{name:<15}|")   # left
print(f"|{name:>15}|")   # right
print(f"|{name:^15}|")   # centre

# Fill character
print(f"|{name:*<15}|")  # fill with *
print(f"|{name:->15}|")  # fill with -

# Numbers — right align by default
for n in [1, 10, 100, 1000]:
    print(f"{n:6d}")
```

## Step 4 — Formatted Table

```python
# Product pricing table
products = [
    ("Apple",  0.99, 150),
    ("Banana", 0.59, 200),
    ("Cherry", 3.99, 75),
    ("Mango",  2.49, 40),
]

print(f"{'Product':<12} {'Price':>8} {'Stock':>7} {'Value':>10}")
print("-" * 40)

total_value = 0
for name, price, stock in products:
    value = price * stock
    total_value += value
    print(f"{name:<12} €{price:>7.2f} {stock:>7} €{value:>9.2f}")

print("-" * 40)
print(f"{'Total stock value':>30} €{total_value:>9.2f}")
```
