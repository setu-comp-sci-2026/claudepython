# Step 4 — Loading Shop from JSON

## 4.1 — Add `from_dict()` to Product

```python
# In product.py
@classmethod
def from_dict(cls, d: dict) -> "Product":
    return cls(
        name=d["name"],
        price=d["price"],
        product_id=d["product_id"]
    )
```

## 4.2 — Add `load_from_json()` to Shop

```python
# In shop.py
def load_from_json(self, filename: str = "shop.json"):
    with open(filename, "r") as f:
        data = json.load(f)
    self.__name = data["shop_name"]
    self.__products = [
        Product.from_dict(p) for p in data["products"]
    ]
    print(f"Loaded {len(self.__products)} products from '{filename}'.")
```

## 4.3 — Auto-load on startup

```python
# In driver.py main()
def main():
    shop = Shop("My Shop")
    try:
        shop.load_from_json()
    except FileNotFoundError:
        print("No previous data found.")

    # ... rest of main loop ...

    # Auto-save on exit:
    shop.save_to_json()
    print("Data saved. Goodbye!")
```

Run the driver, add some products, exit, then run again — your products should persist!
