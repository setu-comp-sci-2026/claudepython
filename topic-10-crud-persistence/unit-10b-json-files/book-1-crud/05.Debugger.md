# Step 5 — Using the VS Code Debugger

## 5.1 — Set a breakpoint

Open `shop.py`. Click in the gutter next to the first line of `find_by_name()`. A red dot appears.

## 5.2 — Start debugging

Press **F5** (or Run → Start Debugging). The terminal will show the shop menu. Type `3` to find a product. When `find_by_name()` is called, execution pauses.

## 5.3 — Inspect variables

In the *Variables* panel on the left, expand *Local* to see `self` and `name`. Hover over `self.__products` to see the list.

## 5.4 — Step through

Press **F10** (Step Over) to advance one line at a time. Watch `p` change in the Variables panel as the loop iterates.

## 5.5 — Use the Debug Console

Click the *Debug Console* tab at the bottom. Type:

```python
name
p.get_name()
p.get_name().lower() == name.strip().lower()
```

Verify the comparison is working correctly.

## 5.6 — Continue

Press **F5** to continue running. The function returns, and the menu reappears.

## 5.7 — Debug a bug

Intentionally introduce a bug: change `name.strip().lower()` to just `name` in `find_by_name()`. Run with the debugger and search for "Apple " (with a trailing space). Observe that it now fails. Fix it and verify.
