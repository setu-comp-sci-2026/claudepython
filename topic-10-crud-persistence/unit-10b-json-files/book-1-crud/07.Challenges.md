## Challenge 2 — Error Recovery with Audit Log

Keep an `errors.log` file. Every time an exception occurs during a menu action, append a timestamped line:

```python
import datetime

def log_error(message: str):
    with open("errors.log", "a") as f:
        timestamp = datetime.datetime.now().isoformat()
        f.write(f"[{timestamp}] {message}\n")
```

Call `log_error(str(e))` in each `except` block.

## Challenge 3 — Data Export

Add a menu option to export the shop to:
- CSV (`products.csv`) with columns `id,name,price`
- Plain text (`shop_report.txt`) with a formatted table

```python
import csv

def export_csv(shop: Shop, filename: str = "products.csv"):
    with open(filename, "w", newline="") as f:
        writer = csv.DictWriter(f,
                    fieldnames=["product_id", "name", "price"])
        writer.writeheader()
        for p in shop.get_all_products():
            writer.writerow(p.to_dict())
    print(f"Exported to {filename}")
```
