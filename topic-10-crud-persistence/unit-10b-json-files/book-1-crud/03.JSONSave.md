# Step 3 — Saving Shop to JSON

## 3.1 — Add `to_dict()` to Product

```python
# In product.py
def to_dict(self) -> dict:
    return {
        "name": self.__name,
        "price": self.__price,
        "product_id": self.__product_id,
    }
```

## 3.2 — Add `save_to_json()` to Shop

```python
# In shop.py
import json

def save_to_json(self, filename: str = "shop.json"):
    data = {
        "shop_name": self.__name,
        "products": [p.to_dict() for p in self.__products]
    }
    with open(filename, "w") as f:
        json.dump(data, f, indent=2)
    print(f"Saved {len(self.__products)} products to '{filename}'.")
```
