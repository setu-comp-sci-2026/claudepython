# Lab 10 — CRUD and Persistence

## Objectives

By the end of this lab you will be able to:

- Implement full CRUD operations in the Shop class
- Handle exceptions with `try/except/else/finally`
- Add `to_dict()` and `from_dict()` to `Product` for JSON serialisation
- Save and load the shop to/from a JSON file
- Use the VS Code debugger to step through code and inspect variables
